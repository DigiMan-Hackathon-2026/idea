# 여기서울 제품 요구사항 PRD v0.1

작성일: 2026-11-23 · 상태: 해커톤 시연 기준 · 구현 기준: `d1f5a5f`

여기서울(ココソウル)은 서울에서 이동하는 일본인이 **역에서 방향을 확인하고, 내린 뒤 가까운 로컬 경험을 직접 시작**하도록 돕는 모바일 웹·PWA다. 일본어로 다음 행동을 안내하고 한국어 원문과 현장에서 보여줄 문장을 함께 제공한다. [기존 B2C 요구사항](B2C_SPEC_v0.1.md) · [구현 및 배포 기준](TRD_v0.1.md)

## 대상과 문제

- 첫 검증 대상은 서울에서 혼자 이동하는 일본인 방문객, 특히 재방문객이다. 경로를 찾은 다음에도 표지판·행선지·출구를 대조하기 어렵거나, 내린 뒤 무엇을 어떻게 시작할지 몰라 장소 방문을 포기한다는 가설을 검증한다.
- 서울 거주 일본인은 언어 교류, 도서관처럼 반복해서 쓸 수 있는 생활 경험의 보조 타깃이다. 이용 자격이나 사전 신청 조건은 퀘스트 상세에 표시한다.
- 이용자가 현장에서 답해야 하는 질문은 세 가지다. **어느 방향으로 타는가**, **어느 출구로 나가는가**, **도착하면 무엇을 하는가**. [일본인 사용자 검증 계획](USER_RESEARCH_v0.1.md) · [지하철 현장 검증 가설](SUBWAY_FIELD_GUIDE_v0.1.md)

## 사용자 흐름

1. 홈에서 원하는 목적·시간·지역을 선택하거나, 지하철 역·출구에서 주변 퀘스트를 찾는다.
2. 퀘스트 상세에서 가까운 역과 출구, 예상 시간·비용, 상세 단계, 공식 정보 확인일, 한국어 문장을 확인한다. 필요한 퀘스트는 오프라인으로 볼 수 있게 저장한다.
3. 지하철 안내는 퀘스트의 도착역을 미리 채운다. 출발역을 선택하면 다음 정차역과 호선별 환승을 보여 준다. 승차 전에는 표지판의 방향과 선택한 경로를 대조한다.
4. 체험은 가입 없이 시작한다. 순서대로 단계를 완료하고, 같은 브라우저에서 이어 하거나 기록을 확인한다. 완료 뒤 피드백과 같은 역의 다음 퀘스트를 제안한다.
5. 역 도감에서 이름 유래를 읽고, 위치 확인을 거쳐 스탬프를 받는다. 완료 기록은 사용자 확인으로 남고, 스탬프는 별도 획득 조건을 따른다. [역에서 시작하는 퀘스트 계획](QUEST_STATION_PLAN_v0.1.md)

## 시연 요구사항과 검수 기준

| 요구 | 사용자에게 보여 줄 결과 | 검수 기준 |
| --- | --- | --- |
| 퀘스트 탐색 | 식도락, 문화체험, 쇼핑, 뷰티, 휴식·산책, 일상 속 새로운 경험의 여섯 카테고리. 역 출구, 현재 위치로 찾은 가까운 역, 1~5호선 코스에서 진입 | 퀘스트를 고르면 상세의 출구·단계와 해당 역이 채워진 지하철 안내로 이어진다. 거리 유형은 직선거리와 도보 경로 시간으로 구분한다. |
| 환승 및 승차 방향 | 1~9호선 경로의 환승과 다음 정차역, 한국어 도움 문장, 카메라 또는 사진으로 승차 방향 확인 | 화살표가 가리키는 인접 역이 경로와 맞으면 맞는 방향, 다르면 다른 방향을 표시한다. 역명만 확인되거나 후보가 여럿이면 방향을 보류한다. |
| 역 내부 안내 | 역 검색, 출구·층·시설·공식 안내 접근 | 자료가 있는 역은 검증한 세부 정보를 보여 주고, 역별로 확보된 정보 수준에 맞춰 복구 행동을 안내한다. |
| 진행과 복구 | 단계 수행, 중단 후 재개, 완료, 피드백, 오류 신고, 기록 조회·삭제 | 다시 열면 같은 진행을 이어 가고, 중복 요청으로 완료가 두 번 생기지 않는다. 오류 때 다시 시도할 수 있다. |
| 스탬프 | 역 이름 이야기, 기기 내 획득 기록, PNG 저장 | 대상 역에서 위치 확인을 통과해야 스탬프를 획득한다. |
| 한·일 및 오프라인 | 일본어 기본, 한국어 전환, 저장한 퀘스트의 출구·단계·주소·요청 문장, 저장한 지하철 안내 | 언어 전환 뒤에도 같은 행동과 결과를 볼 수 있다. 연결이 끊기면 기기에 저장한 공개 안내를 열 수 있다. |

제품의 콘텐츠 우선순위는 식도락 → 문화체험 → 쇼핑 → 뷰티 → 휴식·산책 → 일상 속 새로운 경험이다. 현재 시작 화면과 필터의 표시 순서는 뷰티가 쇼핑보다 앞선다. [카테고리 정의](../src/modules/content/demo-quests.ts)

카탈로그에는 장소형 퀘스트 상세 30개, 출구 좌표가 연결된 장소 29개와 출구 24개, 노선 코스 6개가 있다. 이 수치는 소스에 등록된 범위다. Preview DB에 새 콘텐츠 버전이 공개된 범위는 배포와 별도로 기록한다. 정기 휴무와 신청 조건에는 확인일과 공식 출처를 표시한다. ## 사용성 검증과 후속 우선순위

| 우선순위 | 검증할 질문 | 결과 기록 |
| --- | --- | --- |
| P0 현장 방향 | 일본어 사용자가 처음 보는 열차 방향을 올바르게 확인하고, 반대 표지에서 스스로 멈출 수 있는가 | 정방향·반대·판독 보류를 따로 세고, 잘못된 방향을 맞다고 표시한 사례를 우선 검토한다. iPhone·Android에서 가로·세로, 작은 번호·반사광·흔들림 조건을 포함한다. |
| P0 역에서 체험 시작 | 지도만 이용할 때보다 올바른 출구를 찾고 퀘스트 첫 행동을 혼자 시작하기 쉬운가 | 도움 요청, 재검색, 되돌아감, 첫 행동 완료를 관찰한다. 일본어 사용자 3~5명은 초기 모집 목표다. |
| P1 콘텐츠·언어 | 일본어 안내와 운영 조건을 오독하지 않고 실제 장소를 이용할 수 있는가 | 모어 화자 검수, 날짜·권리·휴무·출구 현장 확인을 별도로 기록한다. |
| P1 카메라 개선 | 실제 영상에서 현재 역, 화살표, 옆 역번호 중 어디서 실패하는가 | 화면 단계별 실패와 읽기까지 걸린 시간을 기록한다. 실제 카메라 해상도 확인과 선명한 프레임 선택은 후속 구현 후보로 둔다. |
| 후속 탐색 | 같은 이름의 버스 정류장 두 곳을 현장에서 구분하는 데 정보가 필요한가 | 신촌 등 한 쌍에서 정류소 번호 대조의 가치부터 검증한다. |

시연 기준은 비공개 Preview다. 공개 운영을 판단하려면 현장 실기기, 일본어 모어 검수, 콘텐츠·개인정보·운영 승인 증거가 필요하다. 예약·결제·정산, 업체 운영 화면, 버스 길찾기, 역내 위치를 지속 추적하는 AR 안내는 후속 범위다. [출시 판정 기준](RELEASE_READINESS_v0.1.md) · [현장 확인 항목](../research/desk/field-check/README.md)
