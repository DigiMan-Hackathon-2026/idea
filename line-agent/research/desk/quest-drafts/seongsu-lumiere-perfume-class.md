# 뤼미에르 퍼퓸 성수점에서 혼자 향수 만들기

작성일: 2026-11-22 · 상태: 예약 페이지 정보 확인 · 업체 문의·현장 검수 전

성수 연무장길의 조향 공방에서 한 사람이 약 1시간 동안 50ml 향수를 직접 만드는 퀘스트다. 문화 체험 첫 후보로 이 클래스를 고른 이유는 예약 페이지에서 가격·시간대·환불 조건을 확인할 수 있고, 여행자가 만든 향수를 그대로 가져갈 수 있는 체험이어서다. 예약부터 강사와의 대화까지 혼자일 때 막히는 지점이 분명하다는 점도 이 서비스가 다루려는 문제와 맞는다. [Fever 한국어 예약 페이지](https://feverup.com/m/136419/ja) · [Fever 영어 예약 페이지](https://feverup.com/m/136419/en?thm=76)

함께 검토한 후보:

- 디뮤지엄(성수): 혼자 관람하기 쉬운 전시관이지만 공식 사이트가 자바스크립트로만 열려 현재 전시·운영 시간·요금을 공식 출처로 확인하지 못했다. 전시가 바뀔 때마다 사실이 달라져 첫 후보에서 제외했다.
- 성수 도자기 공방: 완성품을 3일에서 열흘 뒤에 받아야 해 여행자에게 불리하다. [Klook 성수 도자기 원데이](https://www.klook.com/activity/241433-seongsu-ceramic-workshop-one-day-experience/)

## 한·일 안내 초안

### 1. 클래스 예약하기 · クラスを予約する

예약 페이지에서 날짜·시간과 클래스(Signature A 또는 Premium B)를 골라 한 사람 분을 예약하세요. 구매 후에는 바꾸거나 환불할 수 없으니 일정을 먼저 확인하세요. 피부가 예민하다면 예약 전에 다시 생각해 보세요.

予約ページで日時とクラス（Signature A または Premium B）を選び、1人分を予約してください。購入後は変更や払い戻しができないので、先に予定を確認してください。肌が敏感な方は、予約前にもう一度検討してください。

[예약 페이지 열기 · 予約ページを開く](https://feverup.com/m/136419/ja)

### 2. 공방 찾아가기 · 工房へ行く

연무장길 49의 원창실업 건물 나동 3층 301호로 가세요. 지도가 정확하지 않으면 지도 앱에서 한국어 주소 `서울특별시 성동구 연무장길 49`를 검색하세요. 늦으면 수업 시간이 줄어들 수 있으니 여유 있게 도착하세요.

ヨンムジャン通り49番地、ウォンチャン実業ビルのナ棟3階301号室へ向かってください。地図がずれるときは、韓国語の住所「서울특별시 성동구 연무장길 49」で検索してください。遅れるとクラスの時間が短くなることがあるので、余裕をもって着くようにしてください。

### 3. 예약 확인하고 시작하기 · 予約を伝えて始める

도착하면 예약 확인 메일을 보여 주세요. 설명을 따라가기 어려우면 아래 문장을 보여 주세요.

着いたら予約確認メールを見せてください。説明についていけないときは、下の韓国語を見せてください。

> 예약한 사람이에요. 한국어를 잘 못해서, 천천히 말씀해 주시거나 영어로 설명해 주실 수 있나요?

日本語の意味：予約した者です。韓国語があまりできないので、ゆっくり話していただくか、英語で説明していただけますか。

### 4. 향 고르고 완성품 받기 · 香りを選んで完成品を受け取る

여러 향료를 맡아 보고 마음에 드는 향을 골라 섞어요. 원하는 느낌을 말로 하기 어려우면 아래 문장을 보여 주세요. 끝나면 완성품을 오늘 가져갈 수 있는지 확인하세요.

いくつもの香料をかいで、好きな香りを選んで混ぜます。イメージを伝えにくいときは、下の韓国語を見せてください。終わったら、完成品を今日持ち帰れるか確認してください。

> 이 향이 좋아요. 조금 더 가볍게 하고 싶어요. 완성된 향수는 오늘 가져갈 수 있나요?

日本語の意味：この香りが好きです。もう少し軽くしたいです。完成した香水は、今日持ち帰れますか。

## 현장 확인 기록

방문 전에 업체에 문의할 수 있으면 아래를 먼저 확인한다. 그다음 평일 오후에 한 사람이 예약하고 참여해 본다.

- 한 사람만 예약·참여할 수 있는지, 표시 가격이 1인당 가격인지 확인한다.
- 수업을 영어·일본어로 진행하거나 번역 자료를 주는지, 강사와 소통이 필요한 지점이 어디인지 기록한다.
- 가장 가까운 역과 출구, 건물 입구와 3층으로 가는 동선, 지도 앱의 표시 위치가 실제 입구와 맞는지 확인한다.
- 지각 시 추가 요금이나 시간 단축이 있는지 확인한다(후기에 추가 요금 언급이 있으나 업체 정책은 미확인).
- 완성품을 당일 받는지, 포장과 기내 반입 안내가 있는지 기록한다.
- 한·일 문구를 실제 상황에 맞춰 검수한다. 팀이 촬영하거나 권리를 확보한 이미지가 생기면 등록하고, 초안은 텍스트로 제공한다.
