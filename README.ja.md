# idea

[한국어](README.md) | **日本語**

DigiMan Hackathon 2026 のテーマを決めるために、メンバーが作ったアイデアのデモを集めたリポジトリです。
ここにあるコードはすべて**テーマ選定用のデモ**です。画面と流れを見せるのが目的なので、実際に動く機能は一部だけで、残りは仮のデータで埋めています。

### 1. 地下鉄案内サービス（方向判定＋スタンプ／クエスト＋3D）

- **提案:** 최도일, 한시온, 이상무
- **内容:** ホームの案内板を撮ると「この電車に乗っていいか」を日本語で判定する。3Dマップで電車を追いかけ、駅に着いたらスタンプとクエストを集める。APIをつないで、実際の運行状況に合わせて案内する。
- **根拠:** 7号線の終着駅表記の事例（長岩／石南 方面）
- **コード:** [`idea/doil/subway`](idea/doil/subway)、[`idea/sangmu/kokoseoul`](idea/sangmu/kokoseoul)（ココソウルのウェブ／モバイル、クエストのウェブ・モバイルデモのコード）
- **デモ:**
  - 地下鉄アプリ: https://subway-seven-drab.vercel.app
  - 3D: https://subway-seven-drab.vercel.app/#ride
  - クエスト（Web）: https://yeogiseoul-platform-preview-hjyvtena9-koko-seoul.vercel.app/quests
  - クエスト（モバイル）: https://yeogiseoul-platform-preview-j8m5otr50-koko-seoul.vercel.app/mobile-preview

`subway` デモについて:
- 1ファイルの Web アプリ（PWA）で、日本語と韓国語を切り替えられます。
- 案内板の文字認識は端末の中で行います。まずブラウザの `TextDetector`（Apple 端末では Apple Vision）を使い、使えない場合は Tesseract.js に切り替えます。
- カメラは HTTPS か localhost でしか起動しません。
- 3D画面は Three.js で描いています。Chrome のグラフィック アクセラレーションをオンにしてください。
- 路線の判定、記録の統計、コレクションはデモ用のデータです。

## デモの起動

静的ファイルなので、ビルドせずに開けます。カメラとサービスワーカーを使うときは、ローカルサーバーで開いてください。

```bash
cd idea/doil/subway
python3 -m http.server 8000
# http://localhost:8000
```
