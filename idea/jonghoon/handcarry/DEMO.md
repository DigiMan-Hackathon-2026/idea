# 시연 대본 (5분)

일본인 여행자 핸드캐리 중개 서비스 프로토타입을 노트북 화면공유로 시연하는 대본이다. 왼쪽 시연 패널에서 역할을 바꿔 가며 거래 한 건을 주문부터 정산까지 진행하고, 마지막에 수령 거부 분기를 보여준다.

1~10단계는 `.claude/skills/verify-prototype/journeys/golden-path.spec.ts`와, 11단계는 `journeys/dispute.spec.ts`의 첫 번째 테스트와 1:1로 대응한다. 대본을 고치면 journey도 함께 고친다.

## 준비 (시연 10분 전)

1. 프로덕션 모드로 실행한다. dev 모드보다 화면 전환이 빠르다.

   ```bash
   npm install
   npm run build
   npm run start
   ```

2. 브라우저에서 `http://localhost:3000`을 연다. 창 너비는 1024px 이상(권장 1440px)이어야 시연 패널과 폰 프레임이 나란히 보인다.
3. 시연 패널에서 `데모 초기화` → `확인`을 누른다. 구매자 `내 주문` 화면에서 예시 거래 5건이 보이면 준비가 끝난 것이다.

시연 중 화면이 꼬이면 언제든 `데모 초기화`로 처음 상태로 돌아간다. 데이터는 이 브라우저의 localStorage에만 있다.

## 예상 질문과 답

- **실제로 결제되나요?** 아니요. 결제, 본인인증, 번역은 모두 데모용 가짜(mock)다. PG사와 에스크로 제휴사는 미정이다(PRD).
- **번역은 아무 문장이나 되나요?** 대본에 있는 문장만 번역된다. 그 밖의 문장은 `번역 준비 중`으로 표시된다.
- **환율은 실제 값인가요?** 결제 환율 100엔 = 843.29원은 PRD의 2026-10-12 종가다. 영수증 날짜 환율 851.20원은 시연용 가정값이다.
- **최소 보상금 10%는 정해진 건가요?** 시연용 가정이다. PRD에서 미정이다.
- **가입·인증, 노쇼, 거점 자동 수령 확정은요?** 이번 시연 범위에서 뺐다.
- **일본어 문구는 검수했나요?** 개발 중 작성한 문구라 원어민 검수가 필요하다(`lib/i18n/ja.ts`, `lib/demo/translations.ts`).
