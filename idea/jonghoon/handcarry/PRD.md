# PRD: 일본인 여행자 핸드캐리 중개 서비스 (가칭)

Nov 21, 2026 · @ImJongHoon

## 개요

한국 구매자가 원하는 일본 포켓몬 카드·아이돌 굿즈를, 서울에 오는 일본인 여행자가 일본에서 사서 들고 와 전달하고 원화로 정산받는 P2P 중개 서비스다. 서비스는 상품을 사들이거나 되팔지 않으며, 재고를 갖지 않는다.

**배경**

- 원·엔 환율이 100엔당 843.29원(2026년 10월 12일 종가)으로 2008년 이후 최저 수준이다. 일본인에게 한국 여행 경비 부담이 크다. ([시대일보](https://www.sidae.com/article/2026101309030924568))
- 그런데도 2026년 1\~7월 방한 일본인은 228만 명으로 전년보다 18.8% 늘었다. ([Korea Herald](https://www.koreaherald.com/article/10857702))
- 한국인의 일본 직구는 2026년 1분기 1,705억 원으로 20.4% 늘어 분기 최대를 기록했다. 일본 팬클럽 한정 K팝 굿즈가 상위 품목에 올랐다. ([Herald Biz](https://mbiz.heraldcorp.com/article/10823846))

**문제 정의**

- 한국 구매자: 일본 거주자만 살 수 있는 상품(팬클럽 한정, 추첨·예약 판매, 지역 한정)은 직구나 한국인 여행자로도 구하기 어렵다.
- 일본인 여행자: 엔저로 한국 여행 경비가 부담스럽다. 짐 공간을 보상과 수수료 없는 원화 환전으로 바꿀 방법이 없다.

**결정 이력**

- 처음에는 서비스가 상품을 사들여 되파는 매입형을 검토했다. 재고 위험과 수입자 책임 때문에 Grabr식 중개형으로 바꿨다.
- 취급 품목은 포켓몬 카드와 아이돌 굿즈로 한정한다.
- 서비스명은 미정이다.

## 목표와 성공 지표

MVP의 핵심 지표는 **월 완료 거래 건수**(수령 확정까지 끝난 거래)다.

- 한국 구매자가 일본 거주자만 살 수 있는 포켓몬 카드·아이돌 굿즈를 구할 수 있게 한다.
- 일본인 여행자가 짐 공간으로 보상금을 받고, 상품값으로 쓴 엔화를 원화로 돌려받아 한국 여행 경비 부담을 줄이게 한다.
- 미정: 월 완료 거래 건수의 목표치와 달성 시점
- 미정: 보조 지표(매칭률, 거래액, 여행자 재참여율 등) 채택 여부

## 대상 사용자

사용자는 한국 구매자와 일본인 여행자 두 집단이며, 화면은 한국어와 일본어를 모두 지원해야 한다.

| 구분 | 한국 구매자 | 일본인 여행자 |
| --- | --- | --- |
| 자격 | 한국 거주자라면 누구나(본인인증) | 일본 거주 일본인만 |
| 인증 | 본인인증 | 여권 인증 + SNS 계정 연동 |
| 하는 일 | 주문 등록, 입찰 선택, 에스크로 결제, 수령 확인 | 입찰, 일본에서 구매·증빙, 반입, 전달 |
| 얻는 것 | 일본 거주자 한정 상품 | 보상금 + 상품값의 원화 정산 |
| 내는 것 | 상품가 + 보상금 + 수수료 5% + 세금(발생 시) | 수수료 없음 |

- 미정: 구체적인 페르소나(연령대, 구매 빈도, 여행 빈도)
- 미성년 구매자도 가입할 수 있다. 결제 관련 법적 쟁점은 법무 섹션에 적었다.

## 핵심 사용자 흐름

한 건의 거래는 구매자의 주문 등록으로 시작해 구매자의 수령 확인으로 끝난다. 구매자는 여행자의 입찰을 선택한 뒤 에스크로 결제를 한다.

수령을 거부하면 운영팀이 증빙으로 판정한다. 거점에 맡긴 물건을 찾아가지 않으면 보관 기간이 지난 뒤 자동으로 수령이 확정된다.

## 기능 요구사항

MVP는 한국어·일본어 모바일 웹이며, 주문부터 정산까지 한 건의 거래를 끝낼 수 있는 기능과 자동 번역 채팅만 담는다.

**MVP**

| 기능 | 요구사항 |
| --- | --- |
| 가입·인증 | 구매자 본인인증 / 여행자 여권 인증 + SNS 계정 연동, 일본 거주 일본인만 승인 |
| 주문 등록 | 허용 품목만 선택 가능, 건당 상품가 10만 엔 이하 |
| 입찰 | 여행자가 보상금을 제시(최소 금액 이상), 구매자가 선택 |
| 에스크로 결제 | 입찰 선택 후 상품가(원화 환산) + 선택한 입찰의 보상금 + 수수료 5% |
| 구매 증빙 | 여행자가 영수증·상품 사진 업로드 |
| 전달 방식 선택 | 거점(명동·홍대) 또는 직접 대면 |
| 채팅 | 구매자–여행자 1:1 채팅, 한국어↔일본어 자동 번역 |
| 수령 확인·거부 | 수령 확인 시 정산, 거부 시 운영팀 분쟁 접수 |
| 자동 수령 확정 | 거점 보관 후 일정 기간이 지나면 자동 확정 |
| 정산 | 영수증 날짜 환율로 환산, 선불카드 충전 또는 거점 현금 중 여행자 선택 |
| 노쇼 처리 | 여행자 노쇼 시 구매자 전액 환불 + 여행자 패널티 |
| 운영자 도구 | 분쟁 판정, 거점 입고·출고 기록, 여행자 승인 |

**MVP 제외(후속 후보)**

- 상호 평점·리뷰
- 여행자 일정별 주문 묶기
- 예상 세금 계산기
- 반대 방향(일본 구매자용 한국 상품 핸드케리)
- 네이티브 앱

미정: 운영자 도구의 세부 범위. 위 표의 운영자 도구 항목은 분쟁 판정과 거점 보관 정책을 수행하는 데 필요한 최소한으로 추론한 것이다.

## 수익 모델과 가격 정책

플랫폼 수익은 구매자에게만 받는 수수료(상품가의 5%)다. 여행자에게는 수수료를 받지 않는다.

```latex
\text{구매자 총부담} = \text{상품가} + \text{여행자 보상금(입찰가)} + \text{플랫폼 수수료}(\text{상품가} \times 5\%) + \text{세금(발생 시)}
```

| 항목 | 정책 |
| --- | --- |
| 플랫폼 수수료 | 상품가의 5%, 구매자 부담 |
| 여행자 보상금 | 여행자가 입찰로 제시하고 구매자가 선택 |
| 보상금 형태 | 현금성 보상. 단기방문 여행자의 수익활동 제한에 대한 법률 자문 후 확정 |
| 건당 상품가 상한 | 10만 엔 |
| 세금 | 면세한도 초과로 신고하면 구매자 부담(법무 섹션 참고) |

- 미정: 입찰 보상금의 최소·최대 범위

## 결제·정산·에스크로

구매자는 입찰을 선택한 뒤 원화를 에스크로에 넣고, 여행자는 일본에서 상품값을 먼저 낸 뒤 수령 확인이 끝나면 원화로 정산받는다.

1. 구매자 결제: 구매자가 입찰을 선택하면 상품가(원화 환산) + 선택한 입찰의 보상금 + 수수료 5%를 에스크로에 보관한다.
2. 여행자 구매: 여행자가 자기 돈(엔화)으로 산다. 상한은 건당 10만 엔이다.
3. 환율 확정: 여행자 영수증 날짜의 환율로 상품가를 원화로 환산한다.
4. 차액 처리: 에스크로 금액과 영수증 기준 금액의 차이는 플랫폼이 흡수한다. 구매자 추가 결제나 환불은 없다.
5. 정산: 구매자가 수령을 확인하면 여행자에게 상품가(원화 환산)와 보상금을 지급한다.

| 항목 | 정책 |
| --- | --- |
| 여행자 지급 수단 | 여행자가 선택: 외국인 관광객용 선불카드 충전 또는 거점 현금 |
| 환율 변동 위험 | 플랫폼 부담 |
| 구매자 수수료 | 상품가의 5% |

- 미정: 에스크로 결제 때 쓸 환율과 정산 환율의 기준(어느 은행의 어떤 고시환율인지)
- 미정: 연동할 PG사와 에스크로 제공사, 선불카드 제휴사
- 미정: 여행자가 구매에 실패했을 때(품절, 추첨 낙첨) 구매자 환불 시점

## 신뢰·안전

직원 검수 없이, 여행자의 구매 증빙과 구매자의 수령 확인으로 거래를 검증한다.

| 영역 | 정책 |
| --- | --- |
| 여행자 자격 | 일본 거주 일본인만 |
| 여행자 신원 인증 | 여권 인증 + SNS 계정 연동 |
| 구매 증빙 | 여행자가 영수증과 상품 사진을 업로드 |
| 상품 확인 | 구매자가 수령 때 미개봉·상품 일치를 확인하고 수령 확인 |
| 여행자 노쇼 | 구매자에게 전액 환불, 여행자에게 패널티 |

| 영역 | 정책 |
| --- | --- |
| 가품·파손·불일치 | 구매자가 수령 거부 → 운영팀이 영수증·구매 사진·현장 사진을 검토해 판정 |
| 구매자 미수령 | 여행자는 거점에 맡기고, 일정 기간이 지나면 자동으로 수령 확정(여행자 정산 진행) |

- 미정: 패널티의 단계와 기준(경고 횟수, 이용 정지 조건)
- 미정: 자동 수령 확정까지의 기간, 거점 보관 기간
- 미정: 운영팀 판정 결과별 환불·정산 방식(가품으로 판정되면 여행자가 낸 상품값은 누가 부담하는지 등)

## 법무·규제 체크리스트

현재 세관 정책은 "면세한도(미화 800달러) 초과 시에만 신고"다. 프로토타입을 만든 뒤 신고 의무를 확인하고, 의무가 있으면 세금을 구매자가 부담하는 방식으로 바꾼다.

| 쟁점 | 내용 | 현재 정책 |
| --- | --- | --- |
| 대신 사 온 물건의 휴대품 인정 | 면세는 여행자의 신변용품이 대상이다. 돈을 받고 남을 위해 사 온 물건은 휴대품으로 인정되지 않을 수 있다. ([관세청](https://www.customs.go.kr/kcs/cm/cntnts/cntntsView.do?cntntsId=829&mi=2842)) | 면세한도 초과 시에만 신고. 프로토타입 후 재검토 |
| 미신고 반입 | 신고 없는 수입은 밀수입죄로 5년 이하 징역 또는 벌금 대상이다. ([로톡](https://www.lawtalk.co.kr/posts/179351)) | 위와 같음 |
| 플랫폼의 구매대행업자 해당 여부 | 2019년 관세법 개정으로 구매대행업자가 관세포탈죄 처벌 대상에 들어갔다. ([로톡](https://www.lawtalk.co.kr/posts/176538)) | 미검토 |
| 단속 동향 | 관세청은 2026년 11월 2일\~12월 27일 해외직구 악용 특별단속 중이며, 자가사용 가장 밀수가 대상이다. ([법률신문](https://www.lawtimes.co.kr/news/articleViewAmp.html?idxno=228879)) | — |
| 여행자 체류자격 | 무비자 단기방문 입국자의 수익활동 제한에 보상금이 걸릴 수 있다. | 현금성 보상, 법률 자문 후 확정 |
| 미성년 구매자 | 법정대리인 동의 없는 미성년자 계약은 취소될 수 있다. | 한국 거주자 누구나 가입. 보호자 동의 절차 미정 |
| 현금 지급 | 거점 현금 지급은 기록·자금세탁 방지 의무를 검토해야 한다. | 여행자가 선불카드·현금 중 선택 |

**출시 전 확인**

- [ ] 관세청 사전 질의: 여행자가 대신 사 온 물건의 면세 적용과 신고 의무
- [ ] 관세사 자문: 플랫폼이 구매대행업자에 해당하는지
- [ ] 출입국 전문 변호사 자문: 여행자 현금성 보상의 허용 여부
- [ ] 미성년 구매자 결제와 보호자 동의 방식
- [ ] 에스크로·현금 지급 구조의 전자금융·자금세탁 방지 규제 검토

## 출시 계획과 일정

MVP는 서울(명동·홍대 거점)에서 모바일 웹으로 시작하며, 출시 시점은 아직 정하지 않았다.

1. 프로토타입 개발
2. 세관 신고 의무 확인. 의무가 있으면 전 건 신고 + 구매자 세금 부담으로 정책 변경
3. MVP 출시

- 미정: 출시 목표 시점과 단계별 일정
- 미정: 초기 구매자·여행자 모집 채널
- 미정: 체류자격 법률 자문을 출시 전 조건으로 둘지 여부

## 리스크와 미결 사항

가장 큰 리스크는 "면세한도 초과 시에만 신고" 정책이 밀수입으로 판단될 가능성이다. 다음은 보상금에 걸린 체류자격 문제다.

**리스크**

| 리스크 | 영향 | 대응 |
| --- | --- | --- |
| 면세한도 이하 미신고가 밀수입으로 판단됨 | 여행자 처벌, 플랫폼 책임, 서비스 중단 | 프로토타입 후 관세청 사전 질의, 필요하면 전 건 신고로 전환 |
| 현금성 보상이 단기방문 수익활동으로 판단됨 | 핵심 가치(여행자 보상) 훼손 | 법률 자문 후 확정 |
| 환율 차액을 플랫폼이 흡수 | 엔화가 오르면 건당 손실, 수수료 5%를 잠식 | 차액 모니터링, 필요 시 정책 재검토 |
| 여행자 선결제 부담(건당 최대 10만 엔) | 여행자 참여 저조 | 에스크로로 지급 보장을 명확히 안내 |
| 매칭 유동성 부족 | 주문이 수락되지 않음. 크라우드쉬핑은 오래 버틴 사례가 드묾다(PiggyBee는 10년 넘게 운영하다 종료). ([ShareTraveler](https://sharetraveler.com/piggybee-shutters-crowdsourced-delivery-business/)) | 품목·지역을 좁혀 밀도 확보 |
| 직원 검수 없음 | 가품·불일치 분쟁 증가 | 구매 증빙 필수, 운영팀 판정 |
