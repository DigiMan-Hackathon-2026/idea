# オミヤゲ・ソウル (가칭) — 웹앱 기획서

> 일본 문화 관련 내용은 일반 지식 기반이므로 **일본인 인터뷰로 반드시 검증**할 것.

---

## 1. 한 줄 컨셉

인원·예산·유통기한을 입력하면 **나눠 줄 서울 선물을 골라 주고**, **어디서 살지**, **한국어로 어떻게 살지**, **건넬 때 뭐라고 말할지**까지 알려 주는 일본인용 선물 쇼핑 도우미.

## 2. 해결하려는 문제

- 일본에서는 여행 후 직장 동료·지인에게 나눠 줄 선물(お土産)을 사 오는 문화가 강하다. *(인터뷰 검증 필요)*
- 서울에서는 인원수에 맞는 개수, 예산, 개별 포장 여부, 유통기한, 알레르기를 **한국어 라벨만 보고 판단하기 어렵다.**
- 번역기나 챗봇은 "무엇을 살까"까지만 답하고, **계산과 현지 구매까지 이어 주지 않는다.**

## 3. 타깃

| 구분 | 대상 | 비고 |
|---|---|---|
| 주 타깃 | 서울을 여행하는 일본인 | 발표의 중심 |
| 확장 | 일본의 가족·직장에 선물을 보내려는 서울 거주 일본인 | 향후 확장으로 언급 |

## 4. 사용자 흐름

```
① 받을 사람 입력 → ② 조건 입력 → ③ 추천 결과 → ④ 판매처·구매 문구 → ⑤ 건넬 때 한마디 → ⑥ 쇼핑 체크리스트
```

1. **받을 사람 입력** — 그룹별로 추가 (예: 직장 동료 15명, 가족 2명, 친구 1명). 그룹마다 1인당 예산과 격식 정도 선택.
2. **조건 입력** — 보관 방식(상온/냉장), 귀국일, 짐 부담, 알레르기·기피 재료, 쇼핑하기 편한 장소.
3. **추천 결과** — 그룹별 선물 카드(상품명, 가격대, 개수, 소계)와 추천 이유를 일본어로 표시. 전체 예산 합계 계산.
4. **판매처 안내** — 근처 판매처를 지도에 표시하고 한국어 구매 문구 카드("이거 15개 주세요")를 크게 띄움.
5. **건넬 때 한마디** — 받는 사람에 맞는 일본어 메시지 생성. 예: 「韓国のお土産です。よかったらどうぞ。」
6. **쇼핑 체크리스트** — 산 것을 체크하고 남은 예산 확인.

## 5. 기능 우선순위

| 우선순위 | 기능 |
|---|---|
| **필수** (데모 포함) | 그룹별 조건 입력 · 상품 DB 기반 추천과 근거 설명 · 개수/예산 합계 계산 · 근처 판매처 검색 · 한국어 구매 문구 카드 |
| **있으면 좋음** | 건넬 때 한마디(일본어 메시지) · 쇼핑 체크리스트 |
| **시간이 남을 때만** | 상품 라벨 촬영 → 유통기한·원재료 일본어 번역(알레르기 확인) |
| **이번엔 안 함** | 결제 · 실시간 재고 · 대량의 상품 이미지 |

## 6. 상품 데이터 설계

팀이 직접 정리한 후보 **20~30개** 사용. 가격·유통기한은 **데모 전에 팀이 직접 확인**해서 입력.

| 필드 | 타입 | 예시 |
|---|---|---|
| `id` | string | `p001` |
| `name_ko` / `name_ja` | string | 조미김 도시락 / 味付け海苔(お弁当サイズ) |
| `category` | enum | 김 · 과자 · 차 · 화장품 · 기타 |
| `price_krw` | number | 단위 묶음 가격 |
| `pack_count` | number | 포장 단위 개수 (예: 12) |
| `individually_wrapped` | boolean | 개별 포장 여부 |
| `shelf_life_days` | [min, max] | `[90, 180]` |
| `storage` | enum | `room` · `fridge` |
| `allergens` | string[] | `["小麦", "乳", "大豆"]` |
| `store_types` | string[] | `convenience` · `mart` · `drugstore` · `department` |
| `tags` | string[] | `配りやすい` · `高級感` · `軽い` |

```json
{
  "id": "p001",
  "name_ko": "조미김 도시락",
  "name_ja": "味付け海苔（お弁当サイズ）",
  "category": "nori",
  "price_krw": 5000,
  "pack_count": 12,
  "individually_wrapped": true,
  "shelf_life_days": [180, 365],
  "storage": "room",
  "allergens": ["大豆"],
  "store_types": ["mart", "convenience"],
  "tags": ["配りやすい", "軽い"]
}
```

## 7. 기술 구조

```
[모바일 웹 UI] ──입력──▶ [① 규칙 필터 (코드)]
                              │ 예산·보관·알레르기로 후보 축소
                              ▼
                         [② LLM 추천 (후보 제한)]
                              │ 거른 후보 안에서만 선택, 고정 JSON 스키마로 응답
                              ▼
                         [③ 검증 (코드)]
                              │ 상품 ID 존재 확인, 개수·총액 재계산
                              ▼
[결과 카드] ◀── [④ 판매처 검색: 카카오 로컬 API (현재 위치 기준)]
```

- **핵심 원칙: "LLM이 상품을 지어내지 못하게 막고, 계산은 코드가 책임진다."** — 발표의 기술적 고안 포인트.
- 카카오 로컬 API 카테고리 코드(편의점·대형마트 등)는 공식 문서에서 확인 후 사용.
- 화면 구성: 입력 폼 · 결과 카드 · 지도.

### LLM 응답 스키마 (예시)

```json
{
  "groups": [
    {
      "group_id": "g1",
      "product_id": "p001",
      "reason_ja": "個包装で配りやすく、常温で日持ちします。"
    }
  ]
}
```

→ 코드가 `product_id`를 DB와 대조하고, `ceil(인원 / pack_count)`로 구매 수량, `수량 × price_krw`로 소계를 다시 계산한다.

### 추천 기술 스택 (제안)

| 영역 | 선택지 |
|---|---|
| 프론트 | Next.js(React) 또는 Vite + React, 모바일 우선 레이아웃 |
| 백엔드 | Next.js API Routes 또는 FastAPI |
| 데이터 | JSON 파일 → 필요 시 Supabase/SQLite |
| 지도 | Kakao Maps JS SDK + Kakao Local API |
| LLM | 후보 목록을 프롬프트에 넣고 JSON 출력 강제 |

## 8. 기존 방식과의 차이 (예상 질문 대비)

**Q. "ChatGPT에 물어보면 되지 않나요?"**

- 인원·예산 계산이 정확하고, **검증된 상품 목록만** 추천한다.
- 추천에서 끝나지 않고 **판매처와 한국어 구매 문구**까지 이어진다.
- 일본식 배분 문화에 맞춰 **건넬 때 한마디**까지 준비해 준다.

## 9. 평가 기준 대응

| 항목 (배점) | 대응 |
|---|---|
| 기쁨 제공도 (30) | 선물 고민이 풀리는 기쁨 + 받는 사람이 기뻐하는 장면까지 연결 |
| 기술력·완성도 (25) | 규칙 필터 + 제한된 LLM 생성 + 코드 검증 + 지도 연동 |
| 재미·독창성 (20) | 일본 선물 문화에 특화된 접근 |
| 과제 발견·해결력 (15) | 인터뷰·설문 결과로 근거 제시 |
| 팀 개발 (10) | 데이터 / 프론트 / 백엔드 / 기획 분담 |

## 11. 일본인 인터뷰 질문 (검증용)

1. 한국 여행에서 선물을 사 올 때 가장 고민되는 건 무엇인가요?
2. 몇 명 정도에게 선물을 준비하나요? 예산은 어느 정도인가요?
3. 한국어 라벨 때문에 곤란했던 적이 있나요?
4. 이런 서비스가 있다면 쓰고 싶나요?

## 12. 화면 구성 (디자인 시안 기준)

| # | 화면 | 주요 요소 |
|---|---|---|
| 1 | 홈 | 인사 + 마스코트, "おみやげを探す" CTA, 최근 리스트 |
| 2 | 받을 사람 | 그룹 카드(이름·인원·1인당 예산·격식), 그룹 추가 |
| 3 | 조건 | 보관 방식 토글, 귀국일, 짐 부담, 알레르기 칩, 쇼핑 장소 |
| 4 | 추천 결과 | 그룹별 선물 카드, 추천 이유(일본어), 합계 바 |
| 5 | 판매처 | 지도 + 매장 리스트, 한국어 구매 문구 큰 카드 |
| 6 | 한마디 | 받는 사람별 일본어 메시지, 복사 버튼 |
| 7 | 체크리스트 | 구매 체크, 남은 예산 |

### 디자인 톤

- 크림/피치 베이스의 파스텔 팔레트, 크게 둥근 모서리(20–28px), 부드러운 그림자
- 세리프 헤드라인(「今日のおみやげ」) + 둥근 고딕 본문
- 선물상자 마스코트 「ミヤちゃん」로 친근함 연출
- 컬러: Cream `#FBF5EC` · Peach `#F6B8A0` · Coral `#E8806A` · Sky `#A9CBEB` · Butter `#F4CF6B` · Ink `#2B2522`
