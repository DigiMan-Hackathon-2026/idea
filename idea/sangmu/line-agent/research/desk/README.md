# 데스크 리서치: 서울의 일본인 방문지·일본 관련 장소

작성일: 2026-11-22 · 상태: 웹 검색 기반 초안

[seoul-japan-places.csv](seoul-japan-places.csv)는 첫 지역·퀘스트 후보를 고를 때 참고하려고 모은 장소 30곳입니다.
이 목록은 인터뷰 근거가 아닙니다. [후보 선택 가이드](../CANDIDATE_SELECTION_GUIDE.md)의 evidence ID(`E-`, `F-`, `C-`)로 세지 않습니다. 지역이나 퀘스트를 정할 때는 현장·공식 사실 확인과 사용자 사례를 따로 기록해야 합니다.

[서울 퀘스트 데스크 초안](quest-drafts/README.md)에는 이 목록에서 출발한 종로·을지로 초안과 별도로 조사한 성수 식도락 초안이 있습니다. 공개 후보 선정에는 현장 확인과 사용자 근거가 필요합니다.

## 분류

- `popular`: 일본인 관광객이 많이 가거나 일본 여행 매체가 반복해서 소개하는 곳 (20곳)
- `japan_related`: 일본과 역사·문화적으로 연결된 곳. 일제강점기 근대건축, 일본인 거주지, 일본 문화 기관이 포함됩니다 (10곳)

## 열

| 열 | 뜻 |
| --- | --- |
| `japanese_evidence` | `direct`: 일본 매체·일본인 대상 근거가 있음. `indirect`: 외국인 전체 자료에 일본인 언급이 있음. `none`: 일본인 특정 근거가 없음 |
| `source_status` | `sourced`: 출처 있음. `partial`: 일부만 확인됨. `unsourced`: 출처 없는 데스크 후보 |
| `sources` | 출처 URL. 여러 개이면 ` \| `로 구분 |
| `verify_before_use` | 퀘스트에 쓰기 전에 확인할 점 |

## 한계

- 일본인만 따로 집계한 방문지 순위나 결제 통계는 찾지 못했습니다. 외래관광객조사의 국적별 교차표는 [관광지식정보시스템](https://know.tour.go.kr/stat/fReportsOfForeignerDis19Re.do)의 확정치 보고서에서 확인해야 합니다.
- `popular` 근거의 대부분은 일본 여행 매체의 추천 목록입니다. 실제 방문 비율을 뜻하지 않습니다.
- `nearest_station`은 일반적인 노선 정보로 채웠고, 출처로 확인한 값이 아닙니다. 출구 번호는 확인되지 않았습니다.
- 정확한 주소는 넣지 않았습니다. 장소를 퀘스트에 쓸 때 [콘텐츠 검수 계약](../../docs/CONTENT_VERIFICATION_v0.1.md)에 따라 공식 출처로 확인합니다.
- 개별 업소(P18, P19)는 영업 여부와 방식이 자주 바뀝니다.
- `japan_related`의 일제강점기 역사 장소는 일본인 방문자에게 안내할 때 문구의 민감도를 따로 검토해야 합니다.
