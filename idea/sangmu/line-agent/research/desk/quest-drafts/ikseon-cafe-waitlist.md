## 단계

### 1단계

- 일본어 행동 안내: お店の前に行き、順番待ちの受付方法を確認しましょう。
- 장소명과 한국어 주소: 선택한 카페 (미정)
- 지도 대상: 카페 입구 (미확인)
- 한국어 요청 문구: 없음
- 요청 문구의 일본어 뜻: 없음
- 이용 조건과 확인 출처: 대기 등록 방식 미확인 (S06)
- 완료 자기 확인 문구: お店の前に着いた

### 2단계

- 일본어 행동 안내: 順番待ちに登録しましょう。韓国の電話番号がなくて登録できないときは、下のカードを店員に見せてください。
- 장소명과 한국어 주소: 선택한 카페
- 지도 대상: 없음
- 한국어 요청 문구: 한국 전화번호가 없는데 대기할 수 있어요?
- 요청 문구의 일본어 뜻: 韓国の電話番号がないのですが、順番待ちできますか？
- 이용 조건과 확인 출처: 전화번호 요구 여부 미확인 (S06)
- 완료 자기 확인 문구: 順番待ちに登録できた

### 3단계

- 일본어 행동 안내: 順番が来たら入店して、一人分を注文しましょう。
- 장소명과 한국어 주소: 선택한 카페
- 지도 대상: 없음
- 한국어 요청 문구: 한 명이에요.
- 요청 문구의 일본어 뜻: 一人です。
- 이용 조건과 확인 출처: 1인 이용 가능 여부 미확인 (S02)
- 완료 자기 확인 문구: 入店して注文できた
