# 検討用・架空の案内

日本語確認前 · v0.1 · 実在する店舗やサービスではありません

## エリアAで、一人で小さなクラフト体験

一人で参加できる想定の架空の体験を、三つのステップで案内します。

**デモ体験**

| 確認項目 | 内容 |
| --- | --- |
| エリア | ソウル・エリアA（架空） |
| 所要時間 | 約45分 |
| 料金 | 12,000〜18,000ウォン（架空） |
| 一人での利用 | 一人で利用できることを確認済み（架空の設定） |
| 情報確認日 | 2026年11月21日（架空） |

選んだ「クラフト」と「60分以内」の条件に合っています。

### 始める前に

進行記録は、このブラウザに30日間保存されます。他の端末とは共有されません。

`この案内を始める`

## ステップ1　場所を確認する

韓国語の住所をコピーして、向かう場所を確認します。

**韓国語の住所**

서울특별시 예시구 가상로 1

`韓国語の住所をコピー`

地図が開かない場合は、この住所をコピーして地図アプリで検索します。

`場所を確認した`

## ステップ2　受付で確認する

受付で、次の韓国語カードを見せます。

> 혼자 체험할 수 있나요?

日本語の意味: 一人で体験できますか。

`受付で確認した`

## ステップ3　自分で完了を記録する

案内を確認し終えたら、自分で完了を記録します。この記録は、実際の訪問や参加を証明するものではありません。

`このステップを完了する`

## 完了

三つのステップを完了として記録しました。

これは検討用のデモ記録です。実際の訪問記録ではありません。

`完了した記録を見る`
