# 일본인 사용자 검증 계획 v0.1

작성일: 2026-11-21 · 상태: 인터뷰 실행 전 초안

첫 구현 전에 “서울에서 혼자 새로운 경험을 찾는 일본인, 특히 재방문 관광객이 안내 부족 때문에 행동을 포기하거나 익숙한 선택만 반복하는가”를 확인한다. 인터뷰의 목적은 아이디어에 대한 호감을 얻는 것이 아니라 최근 실제 행동과 포기 사례를 수집해 첫 타깃, 지역, 퀘스트를 정하는 것이다.

일본어 문안은 진행용 초안이다. 실제 인터뷰 전에 일본어 모어 화자에게 자연스러움과 의미를 검수받고, 참여자가 편한 언어를 사용한다.

## 이번 조사에서 내릴 결정

| 결정 | 필요한 증거 | 조사 후 행동 |
| --- | --- | --- |
| 첫 타깃 | 최근 혼자 움직인 상황과 반복되는 불편 | 관광객·거주자·유학생 중 첫 범위를 좁힘 |
| 해결할 문제 | 포기·지연·대체 행동과 당시 부족했던 정보 | 안내 부족 가설을 유지·수정·폐기 |
| 첫 지역 | 실제 사례, 접근성, 팀의 현장 검증 가능성 | 지역 1곳과 예비 지역 1곳 선정 |
| 첫 퀘스트 | 혼자 수행 가능하고 3~5단계로 설명할 행동 | 검증할 퀘스트 1개와 후보 2개 선정 |
| 안내 구성 | 선택 전 꼭 확인한 정보와 이해하지 못한 표현 | 카드·상세·단계 화면의 정보 우선순위 결정 |

인터뷰 3~5명은 탐색 목표이며 통계적 대표성을 의미하지 않는다. 한 사람의 의견보다 서로 독립적인 최근 사례와 관찰된 행동을 우선한다.

## 참여자 기준

### 우선 모집

- 일본어를 주로 사용하는 성인
- 최근 12개월 안에 서울을 방문했거나 서울에서 생활한 경험이 있음
- 서울에서 혼자 반나절 이상 움직인 최근 경험이 있음
- 기존 팀원이 아니며 제품 설명을 미리 자세히 듣지 않음

재방문 관광객 2명 이상을 우선 모집하되 모집이 어려우면 서울 거주자·유학생을 비교군으로 포함한다. 두 집단의 사례를 합쳐 “일본인 전체”의 요구로 표현하지 않는다.

### 모집 기록

개인 식별 정보는 조사 문서와 저장소에 남기지 않는다. 연락처는 모집 담당자의 별도 안전한 채널에서 관리하고 기록에는 `P01`, `P02` 같은 코드만 쓴다.

| 항목 | 기록 값 |
| --- | --- |
| 참여자 코드 | P01 형식 |
| 서울과의 관계 | 첫 방문 / 재방문 / 거주 / 유학 / 기타 |
| 최근 서울 체류 시점 | 월 단위 또는 대략적인 기간 |
| 혼자 이동 경험 | 있음 / 없음, 대략적인 맥락 |
| 인터뷰 언어 | 일본어 / 한국어 / 기타 |
| 녹음 동의 | 동의 / 미동의; 미동의 시 메모만 |

나이, 성별, 직업은 문제와 직접 관련된 구분이 필요할 때만 선택적으로 묻는다. 여권번호, 정확한 주소, 전화번호, 이메일은 연구 기록에 수집하지 않는다.

## 모집 질문

제품 아이디어를 먼저 설명하지 않고 아래 질문으로 적합한 최근 경험이 있는지 확인한다.

1. 최근 12개월 안에 서울을 방문하거나 서울에서 생활한 적이 있나요?
2. 그 기간에 혼자 장소를 찾거나 활동을 선택한 적이 있나요?
3. 그때 계획을 바꾸거나 방문을 포기한 경험이 있나요?
4. 약 30분 동안 당시 경험을 이야기하고 간단한 안내 예시를 봐줄 수 있나요?

일본어 초안:

1. 過去12か月以内に、ソウルを訪れた、またはソウルで生活したことがありますか。
2. その期間に、一人で行く場所や体験を選んだことがありますか。
3. その際、予定を変更したり、行くことを諦めたりした経験はありますか。
4. 当時の経験について30分ほどお話しいただき、簡単な案内例を見ていただけますか。

## 동의 안내

인터뷰 시작 전에 목적, 기록 방식, 중단 가능성을 설명한다.

> 이 인터뷰는 서울에서 혼자 장소나 활동을 선택한 경험을 이해하기 위한 것입니다. 정답은 없으며 서비스 아이디어에 동의할 필요도 없습니다. 답하기 불편한 질문은 건너뛰거나 언제든 중단할 수 있습니다. 이름과 연락처는 연구 기록에 남기지 않습니다. 메모를 남겨도 괜찮을까요? 녹음이 필요하면 별도로 동의를 구하겠습니다.

일본어 초안:

> このインタビューは、ソウルで一人で行く場所や体験を選んだ経験を理解するためのものです。正解はなく、サービスのアイデアに賛成する必要もありません。答えにくい質問は飛ばしても、いつでも中止しても構いません。お名前や連絡先は調査記録に残しません。メモを取ってもよろしいですか。録音が必要な場合は、別途同意をお願いします。

녹음은 명시적으로 동의한 경우에만 한다. 녹음 파일의 저장 위치, 접근자, 삭제일을 인터뷰 전에 알리고 정한 기간이 지나면 삭제한다.

## 30분 인터뷰 진행

### 1. 최근 상황 확인 5분

먼저 가장 최근의 구체적인 사건을 시간순으로 복원한다.

- 가장 최근에 서울에서 혼자 무엇을 하려고 했나요?
- 어디서 아이디어를 얻었고 무엇을 기대했나요?
- 장소를 정하기 전에 어떤 정보를 확인했나요? 실제로 사용한 앱이나 검색어를 보여줄 수 있나요?
- 누구와 상의했거나 어떤 후기·영상·지도를 봤나요?

일본어 초안:

- 最近、ソウルで一人で何をしようとしましたか。
- どこでそのアイデアを知り、何を期待していましたか。
- 場所を決める前に、どのような情報を確認しましたか。実際に使ったアプリや検索語を見せていただけますか。
- 誰かに相談したり、口コミ、動画、地図を見たりしましたか。

### 2. 포기 또는 변경 사례 10분

의견보다 실제 행동을 묻고, “언어가 문제였나요?”처럼 원인을 먼저 제시하지 않는다.

- 가려고 했다가 계획을 바꾸거나 포기한 가장 최근 사례를 이야기해 주세요.
- 처음 계획과 실제 행동은 어떻게 달랐나요?
- 결정을 바꾼 순간에 무엇을 알고 있었고 무엇을 몰랐나요?
- 그 정보를 찾기 위해 무엇을 해봤나요? 어디에서 막혔나요?
- 결국 대신 무엇을 했나요?
- 다시 같은 상황이라면 어떤 정보가 있어야 다른 선택을 할 수 있을까요?

일본어 초안:

- 行こうと思っていたのに、予定を変更したり諦めたりした最近の例を教えてください。
- 最初の予定と実際の行動は、どのように違いましたか。
- 予定を変えた時点で、分かっていたことと分からなかったことは何ですか。
- その情報を探すために何をしましたか。どこで困りましたか。
- 結局、代わりに何をしましたか。
- 同じ状況になった場合、どのような情報があれば別の選択ができそうですか。

포기 사례가 없으면 억지로 만들게 하지 않고, 혼자서도 방문을 결정할 수 있었던 최근 사례에서 어떤 정보와 확신이 도움 됐는지 묻는다.

### 3. 안내 예시 이해 테스트 10분

과거 행동 질문이 끝난 뒤에만 텍스트 또는 종이로 된 퀘스트 예시를 보여준다. 실제 제품처럼 보이는 고충실도 화면은 첫 조사에서 필수가 아니다.

진행자는 설명하지 않고 다음 과제를 준다.

1. 이 안내를 보고 무엇을 할 수 있는지 말해 주세요.
2. 혼자 지금 시작할지 결정해 주세요. 결정하면서 보고 있는 정보와 생각을 소리 내어 말해 주세요.
3. 다음 행동이 무엇인지 찾아보세요.
4. 직원에게 보여주는 한국어 요청 카드가 어떤 뜻인지 설명해 주세요.
5. 아직 불안하거나 확인하고 싶은 점을 표시해 주세요.

일본어 초안:

1. この案内を見て、何ができるのかを説明してください。
2. 一人で今から始めるかどうか決めてください。見ている情報と考えていることを声に出してください。
3. 次に何をすればよいか探してください。
4. 店員に見せる韓国語の依頼カードが、どのような意味か説明してください。
5. まだ不安な点や、確認したい点を教えてください。

참여자가 멈추면 바로 정답을 알려주지 않는다. 어디를 보고 무엇을 기대했는지 물은 뒤, 도움 없이 이해했는지와 도움 후 이해했는지를 구분해 기록한다.

### 4. 마무리 5분

- 이 안내가 있었다면 앞서 말한 실제 상황에서 선택이 달라졌을까요? 어떤 부분 때문에 그런가요?
- 반대로 이 안내가 있어도 시작하지 않을 이유는 무엇인가요?
- 서울에서 혼자 새롭게 해보고 싶지만 아직 하지 않은 일이 있나요?
- 이 문제를 더 잘 아는 사람을 소개해 줄 수 있나요?

일본어 초안:

- この案内があれば、先ほどの実際の状況で選択は変わったと思いますか。どの部分が理由ですか。
- 反対に、この案内があっても始めない理由は何ですか。
- ソウルで一人で新しくやってみたいけれど、まだしていないことはありますか。
- このような経験について詳しい方をご紹介いただけますか。

칭찬이나 기능 요청은 그대로 우선순위로 옮기지 않는다. 어떤 과거 상황 때문에 그런 말을 했는지 후속 질문으로 확인한다.

직접 인용은 의미에 필요한 짧은 구절만 기록하고, 검색 화면이나 사진을 보관하려면 별도 동의를 받는다.

## 첫 지역 선택 기준

인터뷰가 끝난 뒤 후보 지역을 각각 0~2점으로 평가한다. 점수는 토론을 돕는 도구이며 약한 근거를 강한 사실로 바꾸지 않는다.

| 기준 | 0점 | 1점 | 2점 |
| --- | --- | --- | --- |
| 사용자 사례 | 관련 최근 사례 없음 | 한 명의 사례 | 서로 독립적인 두 명 이상의 사례 |
| 혼자 수행 가능성 | 동행·예약 필수 | 조건부 가능 | 혼자 바로 수행 가능 |
| 현장 검증 | 행사 전 확인 어려움 | 일부만 확인 가능 | 팀이 주소·이용 조건·단계를 확인 가능 |
| 안내 가치 | 장소 정보만으로 충분 | 일부 행동 안내 필요 | 행동·표현 안내가 선택을 바꿀 가능성 |
| 데모 적합성 | 핵심을 짧게 보여주기 어려움 | 일부 단계만 시연 가능 | 1~2분에 가치와 완료 흐름 설명 가능 |
| 콘텐츠 안정성 | 가격·이용 조건 불명확 | 변동 항목 존재 | 출처·확인일과 대체 경로 확보 가능 |

사용자 사례와 현장 검증 중 하나라도 0점이면 첫 지역으로 확정하지 않는다. 총점이 같으면 더 적은 외부 의존성으로 검증할 수 있는 지역을 우선한다.

   - 장소·주소:
   - 한국어 요청 문구와 일본어 뜻:
   - 이용 조건·확인 출처:
2. ...

## 공개 전 미확인 사항

실제 정보와 가상 데모는 한 퀘스트에 섞지 않는다. 확인하지 못한 장소를 실제 이용 가능한 콘텐츠처럼 제시하지 않는다.

## 조사 종료 후 판단

### 현재 가설 유지

다음 두 조건을 모두 만족하면 재방문 일본인 혼행객과 행동 안내 가설을 첫 구현 기준으로 유지한다.

- 서로 독립적인 참여자 두 명 이상에게 최근 포기·지연·익숙한 선택으로 대체한 사례가 있다.
- 안내 예시에서 참여자가 도움 없이 가치를 이해하고, 자신의 실제 사례에서 어떤 정보가 선택을 바꿀지 구체적으로 설명한다.

### 가설 수정

안내 부족은 확인되지만 관광객보다 거주자·유학생, 또는 새 장소 발견보다 주문·이용 절차 같은 다른 상황에서 반복되면 타깃과 핵심 문장을 수정한다.

### 가설 폐기 또는 보류

포기 원인이 주로 동행 필요, 가격, 시간, 예약 불가처럼 안내로 해결할 수 없는 조건이거나 안내 예시가 실제 선택에 영향을 주지 않으면 현재 퀘스트 가설을 구현 우선순위에서 내린다.

참여자 수가 적으므로 “검증 완료” 대신 확인한 사례 수, 반대 사례, 남은 불확실성을 함께 기록한다.
