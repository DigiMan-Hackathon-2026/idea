# 지하철 현장 판단·복구 가설 v0.1

작성일: 2026-11-22 · 상태: 사용자 검증 전 demo 계약

## 제품 가설

일본어·역번호·실시간 도착·하차 알림과 일반 경로 검색은 이미 여러 경쟁 앱이 제공한다. 여기서울이 추가로 검증할 문제는 서울에서 혼자 이동하는 일본인 방문객이 경로를 검색한 뒤에도 현장의 개찰구·승강장·행선지를 보고 다음 행동을 확신하기 어렵고, 실수했을 때 경로를 안전하게 복구하기 어렵다는 것이다.

이를 경쟁사에 없는 기능으로 확정하지 않는다. `현장 판단 부담`과 `실수 후 복구`를 기존 앱보다 더 잘 줄일 수 있는지 확인할 가설이다.

## 2D 층별 안내 계약

3D 지도는 보류한다. S-MAP은 지하철 역사 실내 3D를 제공하지만 모바일 지원과 외부 서비스 연동 범위가 확정되지 않았고, 현장에서 빠르게 다음 행동을 고르는 목적에는 회전 가능한 3D보다 단순한 2D가 적합하다는 제품 판단이다.

사용자는 GPS나 자동 실내 위치를 신뢰하는 대신 현재 보이는 층과 개찰구 안팎을 직접 선택한다.

- 3F 승강장
- 2F 개찰구 안쪽
- 2F 개찰구 바깥쪽
- 1F 3번 출구 앞

선택 뒤에는 다음 정보를 제공한다.

1. `3F 승강장 → 2F 개찰구·대합실 → 1F 3번 출구`의 층 관계
2. 공식 역이용안내도의 층·출구 방향 관계를 단순화한 2D 개념도와 현재 위치 표시
3. 다음 분기점에서 대조할 한글·영문·일문·역번호 표지 카드
4. 추측하지 않고 수행할 다음 행동 하나
5. 역무원에게 보여 주거나 복사할 한국어 도움 요청

개념도는 건축 평면도나 정확한 보행 경로가 아니다. 현장 공사·통제와 표지판이 화면보다 우선한다. 실제 통로 모양과 분기점 사진은 촬영일·위치·방향·이용 권리를 검수한 뒤에만 추가한다.

성수역 공식 안내도에서 확인해 demo에 반영한 관계는 다음으로 제한한다.

- 3F에 승강장이 있고 2F로 내려가 개찰구·대합실을 거쳐 1F 출구로 이동한다.
- 1·4번 출구는 뚝섬·용답 쪽, 2·3번 출구는 건대입구 쪽으로 표시돼 있다.
- 3번 출구 이용자는 2F에서 `2·3번 출구·건대입구 방면`을 먼저 확인한 뒤 마지막 분기에서 `3`을 확인한다.

출처 파일은 서울 열린데이터광장의 `서울교통공사 역이용안내도` 최신 ZIP이다. 데이터 페이지 게시일은 2026-08-24이지만 성수역 이미지 내부 표기는 2024-04-16이므로 둘을 화면에 함께 표시한다. 이미지 원본은 모바일 화면에 그대로 넣지 않고 사실 확인 자료로만 사용한다.

## 서울교통공사 API 연결

server는 공공데이터포털의 서울교통공사 API 두 개를 5분 단위로 재검증한다.

| 정보 | operation | 화면 사용 |
| --- | --- | --- |
| 엘리베이터 | `B553766/wksn/getWksnElvtr` | 조회 성공 건수와 점검·고장·중지 등 확인 필요 상태 경고 |
| 빠른 하차 | `B553766/inout/getFstExit` | 방면, 성수역 하차 시 참고할 차량 출입문 번호, 연결 설비 |

인증키는 server-only `SEOUL_METRO_PUBLIC_DATA_SERVICE_KEY`로만 읽고 client, HTML, 오류 로그에 전달하지 않는다. 키가 없거나 provider가 실패하면 추정 데이터를 만들지 않고 `연결 준비 중` 또는 `불러오지 못함`과 현장 확인 행동을 두 언어로 보여 준다. 한 API만 성공하면 성공한 정보만 공개한다.

빠른 하차의 차량 출입문 번호는 성수역에서 내릴 때의 참고 정보이며, 탑승 방향·운행 장애·실제 설비 이용 가능성을 보장하지 않는다. 원문에 없는 일본어를 임의 생성하지 않고 검수된 방향·역·설비 이름만 대응시킨다.

## 복구 계약

사용자는 정상 경로 화면에서 바로 다음 세 가지 복구 상황을 선택할 수 있다.

- 다른 승강장에 있음: 선로를 넘지 않고 2F 대합실에서 확인
- 다른 개찰구로 나옴: 교통카드를 다시 찍기 전에 역무원에게 개찰구 밖 연결 확인
- 다른 출구로 나옴: 무리한 도로 횡단 없이 현재 출구 기준으로 보행 경로 재검색

출발역과 실제 탑승 열차를 모르면 방향·승강장·환승 동선을 추측하지 않는다. NAVER 지도에서 경로를 다시 확인하거나 역무원에게 묻는 행동을 먼저 제공한다.

## 콘텐츠 신뢰 경계

- 성수역의 2호선·외부 역번호 `211`은 서울교통공사 공개 데이터에서 확인한 demo 사실이다.
- 성수역 공식 역이용안내도의 3F·2F·1F 층 관계와 출구 방향은 화면에서 단순화하며 정확한 평면 형상으로 주장하지 않는다.
- 실시간 열차 위치·도착·운행 장애는 여기서울이 제공하거나 보장하지 않는다.
- 역별 개찰구 연결·승강장 방향·환승 분기·현장 사진은 출처와 확인 시각을 가진 콘텐츠로 별도 검수하기 전에는 확정 안내로 공개하지 않는다.
- 현재 화면은 동선 정확도를 입증한 운영 콘텐츠가 아니라 상황형 안내의 사용성을 검증하는 demo다.
- 성수역 출입구 증설 공사로 동선이 바뀔 수 있으므로 `검증 기준일`을 화면에 표시하고 현장 표지를 우선하도록 안내한다.

## 검증 방법

같은 참가자가 기존 지도 앱과 여기서울 시제품으로 서로 다른 경로를 수행하고 사용 순서를 바꾼다.

| 지표 | 관찰 내용 |
| --- | --- |
| 판단 정확도 | 올바른 개찰구·승강장·열차를 선택했는가 |
| 확인 부담 | 멈춤·화면 전환·재검색 횟수가 줄었는가 |
| 독립적 이용 | 다른 사람의 개입 없이 다음 행동을 정했는가 |
| 복구 능력 | 실수 뒤 올바른 경로로 돌아왔는가 |
| 확신과 정확성 | 자신감뿐 아니라 실제 판단도 개선됐는가 |

기존 앱보다 현장 문제를 더 정확하고 적은 부담으로 해결한다는 관찰이 반복될 때만 지하철 전문 서비스로 범위를 좁힌다.
