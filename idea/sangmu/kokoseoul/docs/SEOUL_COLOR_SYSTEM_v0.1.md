# 여기서울 서울색 UI 체계 v0.1

작성일: 2026-11-22 · 상태: 구현 기준

## 출처와 사용 범위

서울특별시가 공개한 `서울 대표색 10`과 공식 색변환표의 웹용 Hex 값을 여기서울의 원색 토큰으로 사용한다. 원본 색의 명칭과 값은 변경하지 않는다. 화면 배경과 상태 배경처럼 더 옅은 색이 필요한 경우 CSS `color-mix()`로 원색과 흰색을 혼합해 파생하며, 파생색을 새로운 서울 공식색으로 부르지 않는다.

## 의미 규칙

- 단청빨간색은 한 화면의 핵심 행동 하나와 현재 단계에 우선 사용한다. 오류만을 뜻하는 색으로 제한하지 않는다.
- 남산초록색은 경로·진행 완료·사용 가능처럼 안전하게 이어지는 상태에 사용한다.
- 서울하늘색은 현재 위치, 외부 지도 정보와 키보드 포커스에 사용한다.
- 은행노란색은 출구 번호, 시간과 확인이 필요한 주의 정보에 사용한다. 흰 글자를 올리지 않는다.
- 기와진회색은 본문과 어두운 카드에 사용하고 순수 검정 사용을 피한다.
- 색만으로 선택·오류·완료를 구분하지 않고 문구, 굵기, 테두리와 `aria` 상태를 함께 제공한다.
- 지하철 노선색과 NAVER 지도처럼 외부 체계의 식별을 위해 정해진 색은 서울색으로 치환하지 않는다. 여기서울 자체 UI의 면·행동·상태만 이 체계를 따른다.

## 화면 구조

- 큰 면은 삼베연미색의 옅은 파생색과 한강은백색을 사용한다.
- 카드 모서리는 작은 반경을 기본으로 하고, 원형은 위치점·노선번호처럼 의미가 있을 때만 사용한다.
- 서울 건축과 표지 체계에서 가져온 직선, 얇은 격자, 상단 색 띠를 공통 모티프로 사용한다.
- 공식 색을 사용한다는 이유로 서울시 로고나 브랜드 자산을 복제하지 않는다. 여기서울의 이름과 정보 구조는 독립적으로 유지한다.

## 접근성

- 일반 본문은 기와진회색 또는 그보다 어두운 파생색을 밝은 면에 사용한다.
- 단청빨간색·남산초록색·기와진회색 위에는 흰색 글자를 사용한다.
- 은행노란색·한강은백색·삼베연미색 위에는 기와진회색 글자를 사용한다.
- 360px, 고대비, 키보드 포커스와 `prefers-reduced-motion`을 화면 변경 때마다 검증한다.
