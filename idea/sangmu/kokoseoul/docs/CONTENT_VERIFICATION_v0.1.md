# 퀘스트 콘텐츠 사실과 권리 검수 v0.1

작성일: 2026-11-21 · 상태: 첫 콘텐츠 선정 전

실제 퀘스트를 공개하기 전에 장소, 가격, 이용 조건, 한국어 요청 문구, 일본어 설명과 이미지의 근거·확인일·사용 권리를 기록한다. 검색 결과나 AI 초안을 사실 근거로 사용하지 않으며, 확인하지 못한 항목은 실제 이용 가능하다고 표현하지 않는다.

## 검수 대상

| 정보 | 필요한 근거 | 갱신 기준 |
| --- | --- | --- |
| 장소명·한국어 주소 | 업체·기관 공식 페이지 또는 현장 확인 | 주소 변경·이전 |
| 운영 시간·휴무 | 공식 공지와 확인일 | 공개 전, 변경 신고 후 |
| 가격·필수 구매 | 공식 가격표·현장 확인 | 공개 전, 가격 신고 후 |
| 혼자 이용 가능 | 운영자 문의·현장 관찰·명시된 정책 | 공개 전, 조건 변경 시 |
| 예약 필요 여부 | 공식 예약 정책 | 공개 전 |
| 단계 행동 | 팀의 실제 수행 또는 가상 demo 명시 | version 공개 전 |
| 한국어 요청 문구 | 의미·상황·존댓말 검수 | version 공개 전 |
| 일본어 안내 | 모어 화자 검수 | 문구 변경 시 |
| 지도 대상 | 주소·장소명·좌표 실제 기기 확인 | 공개 전 |
| 사진·설명 | 직접 제작 또는 명시적 license·허락 | asset 사용 전 |

“블로그 여러 곳에서 봤다”는 운영 시간·가격·혼자 이용 가능의 최종 근거가 아니다. 사용자 후기는 후보 탐색과 문제 발견에만 사용하고 업체 사실은 공식 출처나 현장 확인으로 검증한다.

## 출처 등급

| 등급 | 예 | 사용할 수 있는 범위 |
| --- | --- | --- |
| A | 업체·기관 공식 공지, 직접 확인한 현장 표지, 담당자 답변 | 사실 정보의 주 근거 |
| B | 지도 사업자 장소 정보, 검증 가능한 공공 데이터 | 주소·위치 교차 확인 |
| C | 사용자 후기·영상·블로그 | 문제·후보 발견, 단독 사실 근거 금지 |
| D | 검색 snippet, AI 생성 답변, 출처 불명 repost | 공개 근거로 사용 금지 |

현장 확인도 시점 이후 변경될 수 있으므로 확인일과 확인 방법을 표시한다. 담당자 개인 연락처와 비공개 대화 원문은 Git에 올리지 않고 공개 가능한 요약만 남긴다.

## 퀘스트 출처 기록

퀘스트 후보마다 다음 표를 작성한다.

```markdown
## 사실 정보 출처

| ID | 항목 | 값 | 출처 등급 | 공개 URL 또는 확인 방법 | 확인일 | 확인자 코드 | 다음 확인일 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| S01 | 한국어 주소 |  | A/B |  | YYYY-MM-DD |  |  |
| S02 | 혼자 이용 | confirmed/unknown | A |  |  |  |  |
| S03 | 가격 |  | A |  |  |  |  |
| S04 | 운영 시간 |  | A |  |  |  |  |

## 불일치와 판단

| 항목 | 서로 다른 정보 | 채택한 값 | 판단 이유 | 사용자 표시 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
```

출처가 충돌하면 더 편리한 값을 고르지 않는다. 최신 공식 정보, 현장 확인과 사용자에게 안전한 표현을 우선하고 불확실하면 `unknown` 또는 퀘스트 중지로 처리한다.

## 혼자 이용 조건

`confirmed`는 다음을 모두 만족할 때만 사용한다.

- 한 사람이 예약·입장·주문·체험할 수 있음을 확인했다.
- 최소 인원, 주문 수량, 좌석, 시간대 제한을 확인했다.
- 직원 도움이나 한국어 대화가 필요한 지점을 단계에 적었다.
- 예상 비용과 필수 구매를 시작 전에 표시했다.
- 확인 방법과 날짜를 기록했다.

한 명 방문 사례가 있었다는 사실만으로 항상 혼자 이용 가능하다고 일반화하지 않는다. 조건이 불명확하면 `unknown`으로 표시하고 추천 정렬에서 confirmed보다 뒤에 둔다.

## 운영 시간과 실시간 표현

P0는 실시간 영업 여부를 보장하지 않는다.

허용 표현:

- `2026年11月20日に情報を確認しました。`
- `営業時間は変更される場合があります。出発前に公式情報をご確認ください。`

피할 표현:

- 지금 영업 중
- 반드시 이용 가능
- 예약 없이 언제든 가능
- 오늘 가격이 동일함

실시간 API가 없는데 현재 상태처럼 보이는 badge를 만들지 않는다.

## 한국어 요청 카드

각 문구는 다음을 확인한다.

- 실제 상황에서 직원에게 보여도 의미가 통한다.
- 일본어 뜻이 직역이 아니라 같은 요청을 설명한다.
- 무례하거나 과도한 요구가 아니다.
- 가격·무료 제공·예약·재고를 약속하지 않는다.
- 개인의 건강·알레르기·법적 상태를 대신 보증하지 않는다.

음식 알레르기, 의료, 안전과 법적 해석이 필요한 문구는 P0 일반 카드로 자동 생성하지 않는다. 필요한 경우 전문가·업체 확인과 별도 경고를 거친다.

AI 번역은 초안으로만 사용한다. 모어 화자 검수 전 `reviewedAt`, `reviewedBy`를 채우거나 공개하지 않는다.

## 이미지와 설명 권리

### 사용할 수 있는 후보

- 팀이 직접 촬영·제작하고 등장인물·상표·시설 촬영 조건을 확인한 asset
- 업체·기관이 사용 범위를 서면으로 허용한 asset
- 상업적·수정·재배포 범위가 제품 사용과 맞는 license asset
- license와 attribution 조건을 기록한 공공 asset

### 사용하지 않는 항목

- 검색 결과·지도·SNS에서 저장한 이미지
- 워터마크를 제거한 이미지
- 출처나 license가 불명확한 이미지
- 사용자가 올린 사진을 동의 없이 재사용
- 업체 설명·후기·기사의 긴 문장을 복사한 본문

링크를 표시하는 것만으로 복제 권리가 생기지 않는다. 권리가 불명확하면 이미지 없이 text·직접 제작 icon으로 진행한다.

## demo 콘텐츠

- 실제 업체·가격·주소를 가상 단계와 섞지 않는다.
- 실제 상호를 사용하지 않아도 특정 업체처럼 오인될 표현을 피한다.
- 카드·상세·진행·완료에 demo를 표시한다.
- demo 완료를 실제 방문·성과로 집계하지 않는다.
- 지도 링크가 필요 없는 실내 시연이면 가상 주소를 실제 지도에 검색하게 하지 않는다.

실제 지역 가치를 설명할 때는 익명화된 사용자 사례와 검증한 후보를 demo 완료 기록과 구분한다.

## 변경과 긴급 중지

다음 상황에서는 새 version 공개를 기다리지 않고 quest를 중지한다.

- 주소 이전·폐업·이용 불가
- 혼자 이용 조건이 달라져 사용자가 거절될 가능성
- 가격·필수 구매가 크게 달라져 시작 판단에 영향
- 안전·권리 문제
- 지도 링크가 다른 장소로 연결

중지 이유는 공개 가능한 일본어로 작성한다. 사실 수정은 published row를 바꾸지 않고 새 draft를 검수·공개한다.

## 공개 전 체크

- [ ] 모든 단계가 실제 수행 가능하거나 전체가 demo다.
- [ ] 장소·주소·가격·시간·혼자 이용 조건에 출처와 확인일이 있다.
- [ ] 불확실한 비용·조건을 unknown으로 표시했다.
- [ ] 지도 링크와 주소 복사를 일본어 실제 기기에서 확인했다.
- [ ] 한국어 요청 문구와 일본어 뜻을 함께 검수했다.
- [ ] 일본어 모어 화자 검수 기록이 있다.
- [ ] 이미지·설명 권리와 attribution을 기록했다.
- [ ] demo와 실제 정보를 섞지 않았다.
- [ ] 다음 확인일과 중지 담당자를 정했다.

하나라도 사용자 선택·현장 이용에 중요한 항목이 비어 있으면 실제 콘텐츠로 공개하지 않는다.
