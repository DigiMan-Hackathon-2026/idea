## 단계

### 1단계

- 일본어 행동 안내: 駅の出口から市場の入口まで歩きましょう。入口に着いたら、この手順を完了にしてください。
- 장소명과 한국어 주소: 광장시장 출입구 (주소 미확인)
- 지도 대상: 시장 출입구 (미확인)
- 한국어 요청 문구: 없음
- 요청 문구의 일본어 뜻: 없음
- 이용 조건과 확인 출처: 가까운 역·출구 미확인 (장소 목록에는 종로5가역으로만 기록)
- 완료 자기 확인 문구: 市場の入口に着いた

### 2단계

- 일본어 행동 안내: 食べてみたい屋台を一つ選び、一人で座れるか聞いてみましょう。断られたら、無理をせず別の屋台を選んでください。
- 장소명과 한국어 주소: 광장시장 먹거리 골목 (특정 노점 미정)
- 지도 대상: 없음 (시장 안)
- 한국어 요청 문구: 한 명인데 앉아도 돼요?
- 요청 문구의 일본어 뜻: 一人ですが、座ってもいいですか？
- 이용 조건과 확인 출처: 1인 착석 가능 여부 미확인
- 완료 자기 확인 문구: 座る場所が決まった

### 3단계

- 일본어 행동 안내: 下の韓国語カードを見せて、一人分を注文しましょう。
- 장소명과 한국어 주소: 2단계에서 고른 노점
- 지도 대상: 없음
- 한국어 요청 문구: 이거 1인분 주세요.
- 요청 문구의 일본어 뜻: これを一人分ください。
- 이용 조건과 확인 출처: 1인분 주문 가능 여부·메뉴 이름 미확인
- 완료 자기 확인 문구: 注文できた

### 4단계

- 일본어 행동 안내: 食べ終わったら会計をしましょう。カードが使えるか分からないときは、下のカードを見せてください。
- 장소명과 한국어 주소: 2단계에서 고른 노점
- 지도 대상: 없음
- 한국어 요청 문구: 카드 돼요?
- 요청 문구의 일본어 뜻: カードは使えますか？
- 이용 조건과 확인 출처: 결제 방식 미확인 (S06)
- 완료 자기 확인 문구: 会計が終わった
