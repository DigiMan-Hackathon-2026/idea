## 단계

### 1단계

- 한국어 행동 안내: 네이버 지도에서 종로32길 5에 있는 순희네빈대떡을 찾아요. 지도가 열리지 않으면 `서울 종로구 종로32길 5`를 복사해 검색해요.
- 일본어 행동 안내: NAVERマップで「종로32길 5」にある「순희네빈대떡」を探します。地図が開かないときは「서울 종로구 종로32길 5」をコピーして検索しましょう。
- 장소명과 한국어 주소: 순희네빈대떡 (서울 종로구 종로32길 5)
- 지도 대상: [네이버 지도에서 주소 찾기 · NAVERマップで住所を探す](https://map.naver.com/p/search/%EC%84%9C%EC%9A%B8%20%EC%A2%85%EB%A1%9C%EA%B5%AC%20%EC%A2%85%EB%A1%9C32%EA%B8%B8%205)
- 한국어 요청 문구: 없음
- 요청 문구의 일본어 뜻: 없음
- 이용 조건과 확인 출처: 서울관광재단은 종로5가역 8번 출구를 안내함 (S01)
- 완료 자기 확인 문구: 가게에 도착했어요 · 店に着いた

### 2단계

- 한국어 행동 안내: 직원에게 혼자 앉아 먹을 수 있는지 물어봐요. 자리가 없다면 포장이나 대기가 가능한지 물어봐요.
- 일본어 행동 안내: スタッフに1人で座って食べられるか聞きます。席がなければ、持ち帰りや順番待ちができるか聞きましょう。
- 장소명과 한국어 주소: 순희네빈대떡 (서울 종로구 종로32길 5)
- 지도 대상: 없음 (시장 안)
- 한국어 요청 문구: 한 명인데 앉아도 돼요?
- 요청 문구의 일본어 뜻: 一人ですが、座ってもいいですか？
- 이용 조건과 확인 출처: 1인 착석 가능 여부 미확인
- 완료 자기 확인 문구: 먹고 갈지 포장할지 정했어요 · 店内で食べるか持ち帰るか決めた

### 3단계

- 한국어 행동 안내: 메뉴판의 ‘녹두빈대떡’을 가리키고 한 장 주문할 수 있는지 물어봐요. 수량과 가격을 확인하고 주문해요.
- 일본어 행동 안내: メニューの「녹두빈대떡」を指して、緑豆のチヂミを1枚注文できるか聞きます。枚数と値段を確かめてから注文しましょう。
- 장소명과 한국어 주소: 순희네빈대떡 (서울 종로구 종로32길 5)
- 지도 대상: 없음
- 한국어 요청 문구: 녹두빈대떡 한 장만 주문할 수 있나요?
- 요청 문구의 일본어 뜻: 緑豆のチヂミを1枚だけ注文できますか。
- 이용 조건과 확인 출처: 메뉴 이름 확인 (S01) · 소량 주문 가능 여부 미확인
- 완료 자기 확인 문구: 빈대떡을 주문했어요 · ピンデトクを注文できた

### 4단계

- 일본어 행동 안내: 会計する場所とカード払いができるか、スタッフに聞きましょう。
- 장소명과 한국어 주소: 순희네빈대떡 (서울 종로구 종로32길 5)
- 지도 대상: 없음

- 요청 문구의 일본어 뜻: カードは使えますか？
- 이용 조건과 확인 출처: 결제 방식 미확인 (S06)
- 완료 자기 확인 문구: 계산했어요 · 会計が終わった
