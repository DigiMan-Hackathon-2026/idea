# 역 스탬프·역명 유래 카드 초안

작성일: 2026-11-22 · 상태: 전체 원천 데이터 정리, 일본어 카드 20개 초안

역에 도착하면 그 역의 스탬프를 받고, 역명의 한자와 유래를 일본어로 읽는 방향을 검토하기 위한 자료입니다. 인터뷰 근거가 아니므로 evidence ID로 세지 않습니다.

## 원천 데이터

| 항목 | 값 |
| --- | --- |
| 데이터셋 | [서울교통공사_역명의 유래 (OA-12036)](https://data.seoul.go.kr/dataList/OA-12036/S/1/datasetView.do) |
| 제공 | 서울교통공사 수송운영처 |
| 범위 | 274건, 역명 기준 237개 역 |
| 노선 | 1~8호선. 9호선은 종합운동장 1건뿐이고 신분당선 등은 없음 |
| 필드 | `SUBW_ID` 역 ID, `STTN` 역명, `SBWY_ROUT_LN` 호선, `STTN_ORGN` 역명 유래 |
| 이용허락범위 | 제한 없음 |
| 갱신 | 일간 |
| 제공 방식 | Open API `TbSeoulmetroStOrigin` (서울 열린데이터광장 일반 인증키) |

## 데이터 품질

- 원문이 빈 역은 없습니다. 길이는 23~435자, 중간값 115자입니다.
- 86개 역의 원문에 한자가 있습니다.
- 34개 역의 원문에 "전해오고 있다", "구전", "~라는 설" 같은 전설·이설 표시가 있습니다.
- 여러 호선에 걸친 35개 역 중 5개 역만 호선별 원문이 다르고, 차이는 띄어쓰기·오타 수준입니다.

## 카드 초안 20개

일본인이 많이 가는 장소 목록(브랜치 `research/seoul-japan-places`)에 나온 관광 동선의 역을 먼저 골랐습니다.

왕십리, 답십리, 압구정, 명동, 성수, 이태원, 회현, 종로3가, 경복궁, 광화문, 안국, 동대문역사문화공원, 동대문, 홍대입구, 한강진, 망원, 서울역, 시청, 잠실, 을지로입구

`relatedStations`로 같은 이야기를 공유하는 역을 연결했습니다. 예를 들어 왕십리와 답십리는 무학대사 전설로, 안국과 망원은 월산대군으로 이어집니다.

| 필드 | 뜻 |
| --- | --- |
| `hanja`, `hanjaSource` | 역명 한자. `official`은 원문에 있음, `supplement`는 원문에 없어 보충함, `none`은 한자 없음 |
| `readingKoKana`, `readingJaOn` | 한국어 발음의 가타카나 표기와 일본어 음독 |
| `kanjiNoteJa` | 한자 한 글자씩의 뜻 |
| `storyJa`, `storyKind` | 원문만 근거로 쓴 일본어 이야기. `legend`는 전설, `history`는 기록 |
| `supplementJa` | 원문에 없는 보충 설명. 모두 검수 필요 |
| `reviewNotesKo` | 표기 방침·사실 확인이 필요한 점 |
| `officialOriginKo` | 근거가 된 원문 |

## 검수가 필요한 점

- **일본인에게 민감한 표현**: 원문의 "임진왜란", "해방", "광복"을 일본어로 어떻게 쓸지 정해야 합니다. 초안은 「壬辰倭乱（文禄・慶長の役）」, 「解放」, 「光復（解放）」으로 썼습니다.
- **일제강점기 지명**: 을지로입구 원문의 "황금정(黃金町)"은 일본식 지명입니다. 일본어 안내 문구의 민감도를 검토해야 합니다.
- **낡은 정보**: 원문의 "보물 제1호", "사적 32호" 같은 문화유산 지정번호는 카드에서 뺐습니다.
- **연도 확인**: 원문의 연도 중 다른 자료와 다를 수 있는 것(예: 황금정 개칭 1941년)은 `reviewNotesKo`에 남겼습니다.

## 작성 규칙

- 이야기는 원문에 있는 사실만 씁니다. 원문에 없는 한자·설명은 `supplementJa`나 `hanjaSource: supplement`로 분리합니다.
- 원문에 한자가 없는 인명·지명은 가타카나로 씁니다.
- 전설은 일본어에서도 「〜と言われています」「〜という言い伝えがあります」처럼 사실과 구분합니다.
- 카드는 미리 만들어 검수한 뒤 고정 콘텐츠로 씁니다. 실행 중에 LLM으로 생성하지 않습니다.
- 모든 일본어 문장은 모어 화자 검수 전 초안입니다.
- 출처 표시는 "서울교통공사 역명의 유래 (서울 열린데이터광장)"로 합니다.
