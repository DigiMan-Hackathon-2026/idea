# 역 스탬프·역명 유래 카드 초안

작성일: 2026-11-22 · 상태: 전체 237개 역 일본어 카드 초안

역에 도착하면 그 역의 스탬프를 받고, 역명의 한자와 유래를 일본어로 읽는 방향을 검토하기 위한 자료입니다. 인터뷰 근거가 아니므로 evidence ID로 세지 않습니다.

| 항목 | 값 |
| --- | --- |
| 데이터셋 | [서울교통공사_역명의 유래 (OA-12036)](https://data.seoul.go.kr/dataList/OA-12036/S/1/datasetView.do) |
| 제공 | 서울교통공사 수송운영처 |

| 필드 | `SUBW_ID` 역 ID, `STTN` 역명, `SBWY_ROUT_LN` 호선, `STTN_ORGN` 역명 유래 |

## 데이터 품질

- 원문이 빈 역은 없습니다. 길이는 23~435자, 중간값 115자입니다.
- 86개 역의 원문에 한자가 있습니다.
- 34개 역의 원문에 "전해오고 있다", "구전", "~라는 설" 같은 전설·이설 표시가 있습니다.
- 여러 호선에 걸친 35개 역 중 5개 역만 호선별 원문이 다르고, 차이는 띄어쓰기·오타 수준입니다.

## 카드 초안

237개 역 모두 카드가 있습니다.

| 항목 | 수 |
| --- | ---: |
| 원문에 한자가 있는 역명 (`official`) | 45 |
| 원문에 없어 한자를 보충한 역명 (`supplement`) | 172 |
| 한자가 없는 고유어 역명 (`none`) | 20 |
| 전설로 분류한 이야기 (`legend`) | 37 |
| 보충 설명이 있는 카드 | 32 |
| 검수 메모가 있는 카드 | 56 |
| 다른 역과 이야기로 이어진 카드 | 161 |

`relatedStations`는 같은 인물·전설·지명을 공유하는 역을 양방향으로 연결합니다. 예를 들어 왕십리·상왕십리·답십리·무악재는 무학대사로, 안국과 망원은 월산대군으로 이어집니다.

| 필드 | 뜻 |
| --- | --- |
| `hanja`, `hanjaSource` | 역명 한자. `official`은 원문에 있음, `supplement`는 원문에 없어 보충함, `none`은 한자 없음 |
| `readingKoKana`, `readingJaOn` | 한국어 발음의 가타카나 표기와 일본어 음독 |
| `kanjiNoteJa` | 한자 한 글자씩의 뜻 |
| `storyJa`, `storyKind` | 원문만 근거로 쓴 일본어 이야기. `legend`는 전설, `history`는 기록 |
| `supplementJa` | 원문에 없는 보충 설명. 모두 검수 필요 |
| `reviewNotesKo` | 표기 방침·사실 확인이 필요한 점 |
| `officialOriginKo` | 근거가 된 원문 |

## 한자 확인

카드의 역명 한자를 하나씩 확인해 `hanjaCheck`에 근거를 남겼습니다.

| `hanjaCheck.status` | 뜻 | 수 |
| --- | --- | ---: |
| `wikipedia_station` | 한국어 위키백과 역 문서의 역명 한자와 일치 | 172 |
| `wikipedia_dong` | 위키백과 동 문서의 동 이름 한자와 일치 | 30 |
| `wikipedia_place` | 위키백과 지명 문서와 일치 | 1 |
| `official_text` | 공식 원문에 한자가 있음 | 13 |
| `not_applicable` | 한자가 없는 고유어 역명 | 20 |
| `unverified` | 위키백과에 한자 표기가 없음(강동구청, 강변) | 2 |

확인 과정에서 역명 한자 10개를 고쳤습니다: 사당(舍堂), 양평(楊平), 합정(合井), 대청(大廳), 총신대입구(總神大入口), 암사(岩寺), 응암(鷹岩), 교대(敎大), 동대문역사문화공원(歷), 양천구청(陽川區廳). 사당·양평·합정은 원문이 설명하는 유래의 한자와 지금 역명 한자가 달라, 한자 풀이에 둘의 차이를 적었습니다.

## 원문 처리

- **사실은 원문 그대로 씁니다.** 일본과 관련된 역사도 원문의 사실을 빼지 않습니다. 용어는 일본어 표준 표기로 옮깁니다.

| 원문 | 카드 표기 |
| --- | --- |
| 일제, 일제가 | 日本、日本が |
| 일제강점기, 일제시대, 일제때 | 日本統治時代 |
| 광복 | 光復（解放） |
| 해방 | 解放 |
| 한일합방 | 韓日併合（韓国併合） |
| 임진왜란 | 壬辰倭乱（文禄・慶長の役） |
| 왜군 | 倭軍（日本軍） |

- **원문 오기는 고쳐서 쓰고 `factChecksKo`에 근거를 남깁니다.** 예: 태릉입구 '원순왕후'→인순왕후, 불암산 '송악'→송낙, 녹사평 '錄莎坪'→綠莎坪, 삼성 '당나무'→닥나무.
- **원문끼리 다를 때는 각 역의 원문을 따릅니다.** 을지로4가는 원문대로 1914년이며 외부 자료와도 맞습니다. 을지로입구·을지로3가 원문의 1941년은 외부 자료(1914년)와 달라 `reviewNotesKo`에 남겼습니다.
- **문화유산 지정번호는 뺍니다.** 2021년에 지정번호 표기가 폐지되어 "보물 제1호" 같은 번호는 쓰지 않습니다.
- **성신여대입구 원문의 낮잡는 옛말은 쓰지 않습니다.**

## 남은 확인 항목

`reviewNotesKo`가 있는 카드 12개는 사람의 확인이 필요합니다: 남한산성입구·산성·신흥(백제 도읍지 서술), 동묘앞(영조 15년 연도), 을지로입구·을지로3가(황금정 연도), 내방·신답(원문이 끊기거나 추정만 있음), 신정네거리(新機/新幾), 이촌(移村/二村), 철산(牛/鐵 동음 해석), 성신여대입구(표현).

## 작성 규칙

- 이야기는 원문에 있는 사실만 씁니다. 원문에 없는 한자·설명은 `supplementJa`나 `hanjaSource: supplement`로 분리합니다.
- 원문에 한자가 없는 인명·지명은 가타카나로 씁니다.
- 전설은 일본어에서도 「〜と言われています」「〜という言い伝えがあります」처럼 사실과 구분합니다.
- 카드는 미리 만들어 검수한 뒤 고정 콘텐츠로 씁니다. 실행 중에 LLM으로 생성하지 않습니다.
- 일본어는 だ체(보통체)로 씁니다. 나중에 바꿀 수 있습니다.
- 모든 일본어 문장은 모어 화자 검수 전 초안입니다.
- 출처 표시는 "서울교통공사 역명의 유래 (서울 열린데이터광장)"로 합니다.
