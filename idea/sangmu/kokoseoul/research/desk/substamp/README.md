# 역 스탬프·역명 유래 카드 샘플

작성일: 2026-11-22 · 상태: 데이터 확인과 일본어 카드 샘플

역에 도착하면 그 역의 스탬프를 받고, 역명의 한자와 유래를 일본어로 읽는 방향을 검토하기 위한 자료입니다. 인터뷰 근거가 아니므로 evidence ID로 세지 않습니다.

## 원천 데이터

| 항목 | 값 |
| --- | --- |
| 데이터셋 | [서울교통공사_역명의 유래 (OA-12036)](https://data.seoul.go.kr/dataList/OA-12036/S/1/datasetView.do) |
| 제공 | 서울교통공사 수송운영처 |
| 범위 | 1~8호선 274건. 환승역은 호선마다 따로 있음 |
| 필드 | `SUBW_ID` 역 ID, `STTN` 역명, `SBWY_ROUT_LN` 호선, `STTN_ORGN` 역명 유래 |
| 이용허락범위 | 제한 없음 |
| 갱신 | 일간 (2026-11-21 갱신 확인) |
| 제공 방식 | Open API `TbSeoulmetroStOrigin`만 있음. 파일 내려받기 없음 |

공개 `sample` 키는 한 번에 5건까지만 받을 수 있습니다. 274건 전체를 받으려면 서울 열린데이터광장에서 인증키를 발급받아야 합니다. 9호선, 신분당선 등 서울교통공사가 운영하지 않는 노선은 이 데이터에 없습니다.

## 데이터 품질 (샘플 16건 확인)

- 대부분 한두 문장의 짧은 설명이며, 왕십리(往十里), 성수(聖水), 이태원(梨泰院)처럼 한자가 원문에 들어간 역이 많습니다.
- 전설은 원문에서 이미 "~라 전해오고 있다", "구전이 있는데", "일설에 의하면"으로 구분합니다.
- 같은 역의 호선별 설명은 같거나 거의 같습니다. 카드는 역 단위로 하나만 만들면 됩니다.

## 카드 샘플

[station-cards.sample.json](station-cards.sample.json)에 6개 역(왕십리, 답십리, 압구정, 명동, 성수, 이태원)의 일본어 카드를 넣었습니다. 왕십리와 답십리는 같은 무학대사 전설로 이어져 있어 `relatedStations`로 연결했습니다.

| 필드 | 뜻 |
| --- | --- |
| `hanja`, `hanjaSource` | 역명 한자. `official`은 원문에 있음, `supplement`는 원문에 없어 보충함 |
| `readingKoKana`, `readingJaOn` | 한국어 발음의 가타카나 표기와 일본어 음독 |
| `kanjiNoteJa` | 한자 한 글자씩의 뜻 |
| `storyJa`, `storyKind` | 원문만 근거로 쓴 일본어 이야기. `legend`는 전설, `history`는 기록 |
| `supplementJa` | 원문에 없는 보충 설명. 모두 검수가 필요함 |
| `official.originKo` | 근거가 된 원문 |

## 작성 규칙

- 이야기는 원문에 있는 사실만 씁니다. 원문에 없는 내용은 `supplementJa`나 `hanjaSource: supplement`로 분리합니다.
- 전설은 일본어에서도 「〜と言われています」「〜という言い伝えがあります」처럼 사실과 구분합니다.
- 카드는 미리 만들어 검수한 뒤 고정 콘텐츠로 씁니다. 실행 중에 LLM으로 생성하지 않습니다.
- 모든 일본어 문장은 모어 화자 검수 전 초안입니다.
- 출처 표시는 "서울교통공사 역명의 유래 (서울 열린데이터광장)"로 합니다.
