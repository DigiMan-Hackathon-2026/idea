# 안내 예시 사용 규칙

이 폴더의 자료는 사용자 인터뷰 후반에 안내 구조를 관찰하기 위한 저충실도 자극물이다. 실제 서비스, 공개 콘텐츠, 첫 지역·퀘스트 후보가 아니다. 참여자에게는 자극물 파일만 보여 주고 이 진행 규칙은 보여 주지 않는다.

## 현재 자극물

- [가상 안내 예시 v0.1](TEXT_GUIDANCE_DEMO_v0.1.md)
- [올리브영에서 저장한 화장품 찾기](OLIVE_YOUNG_SHOPPING_CARD_v0.1.md) · [비교 테스트 진행안](../desk/OLIVE_YOUNG_SHOPPING_TEST_v0.1.md)

상태는 일본어 모어 화자 검수 전이다. 검수 전 세션에서 사용했다면 해당 한계를 인터뷰 기록과 합성에 표시한다.

## 사용 시점

최근 실제 사건과 포기·대체 행동 질문을 모두 끝낸 뒤에만 보여 준다. 예시를 먼저 보여 주면 참여자가 과거 사건을 제품 기능에 맞춰 재구성할 수 있다.

진행 순서:

1. `완성 서비스가 아닌 검토용 가상 예시`라고만 설명한다.
2. 참여자에게 처음부터 끝까지 30초 정도 혼자 보게 한다.
3. [세션 진행 가이드](../INTERVIEW_SESSION_GUIDE.md)의 다섯 과제를 순서대로 준다.
4. 설명 없이 한 행동과 진행자 도움 뒤 행동을 분리해 기록한다.
5. 지역 A나 craft 자체의 선호는 첫 지역·퀘스트 근거로 세지 않는다.

## 고정과 변경

- 한 조사 회차의 첫 3개 인터뷰에서는 같은 version을 유지한다.
- 의미를 막는 오타·번역 오류는 수정할 수 있지만 변경 전후 참여자를 구분한다.
- 정보 순서·문구·단계를 바꾸면 새 version 파일을 만들고 변경 이유를 기록한다.
- 참여자마다 다른 설명을 덧붙이지 않는다.
- prototype 오류로 과제를 수행하지 못하면 사용자 실패로 세지 않는다.

## 의도적으로 확인하는 항목

| 관찰 | 성공 기준 | 해석 금지 |
| --- | --- | --- |
| 제공 가치 | 혼자 할 활동과 행동 안내임을 도움 없이 설명 | “좋다”는 말만으로 가치 검증 |
| 시작 결정 | 결정과 사용한 정보를 구체적으로 말함 | 가상 활동을 시작한다는 답을 실제 수요로 계산 |
| 다음 행동 | 주소 확인 또는 첫 단계 찾음 | 진행자 설명 뒤 성공을 무도움 성공으로 계산 |
| 한국어 카드 | 질문의 뜻과 보여 줄 상황을 설명 | 한국어 발음 능력 평가 |
| 남은 불안 | 빠진 정보·조건을 구체적으로 지적 | 기능 요청을 자동 우선순위로 이동 |

이 자극물은 화면 사용성의 최종 근거가 아니다. 버튼 위치, 터치, 접근성은 실제 구현 뒤 별도 모바일 관찰로 검증한다.

## 지역·퀘스트 결정에서 제외할 것

예시의 `지역 A`, 가상 craft 활동, 가격, 주소에 대한 반응은 실제 사례가 아니다. 첫 지역과 퀘스트는 다음에서만 고른다.

- 참여자가 예시를 보기 전에 말한 최근 실제 사건
- 서로 독립적인 두 명 이상의 포기·대체 행동
- 팀이 실제로 확인할 수 있는 혼자 이용 조건·주소·가격·권리
- [퀘스트 후보 양식](../quest-candidates/TEMPLATE.md)의 근거와 검수 상태

참여자가 “이런 craft를 하고 싶다”고 말하면 최근 실제 검색·지출·포기 사건을 후속 질문으로 확인한다. 사건이 없으면 아이디어로만 기록한다.

## 파일 표시 방식

모바일 Markdown viewer 또는 인쇄물 한 장으로 보여 준다. 브라우저 탭·파일 경로·repository 정보가 보이지 않게 하며, 실제 링크나 지도 앱을 열지 않는다. 참여자가 스크롤할 수 있어야 하고 진행자는 먼저 위치를 가리키지 않는다.

화면 캡처와 참여자의 얼굴·음성은 이 폴더에 저장하지 않는다.
